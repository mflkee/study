Пакет для подачи **5 отдельных заявок** в IEK DIGITAL HelpDesk по дефектам, найденным на стенде
курса (бета `1.3.10.33235 / 2.0.4_RC_20260622.1`). Вендор 2026-10-13 перенаправил нас из почты
в HelpDesk и прислал регламент бетта-теста — разбор регламента в
[`rules-beta-test-ms4d.md`](rules-beta-test-ms4d.md).

**Решение (2026-10-16): все дефекты воспроизводим и снимаем только на Astra Linux SE 1.8.6** —
это официально поддерживаемая ОС, а Arch + niri упоминается в заявках одной строкой как второй стенд.
Порядок работ и страховка — в [`protocol-astra.md`](protocol-astra.md).

## Три факта, которые дают этому пакету вес

1. **Архив проекта не нужно искать отдельно.** «Отчёт об ошибках» из среды уже содержит внутри
   `Быстрый старт.zip` — полный архив проекта (проверено вскрытием), т.е. требование
   «приложите проект» закрывается одним файлом.
2. **По дефектам 2 и 3 у нас есть данные из самой модели, а не только «на глаз».** В хранилище
   видно: у окна 42089 вообще нет `Designer.Layout.Width/Height` ни в сохранённом состоянии,
   ни в одной операции журнала; правка «Расположения» не пишется в модель, тогда как правка
   «Параметров окна» (Начальные значения) сохраняется; у перенесённых кнопок размеры удаляются
   операцией «Откат» (`action_type = 2`) и в итоге равны нулю.
3. **Дефект 4 объясняет, почему их собственный отчёт об ошибках в Linux приходит без сведений
   о системе**: `sysinfo.txt` внутри `ErrorReports.zip` содержит исключение `Win32Exception` про
   `systeminfo` вместо информации об ОС.
