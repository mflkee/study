# Заявка 5. Перенос объекта на мнемосхему: элементы без размеров, редактор «застревает»

> Черновик для HelpDesk. Продукт: **MasterSCADA 4D**, галочка **«БЕТА-ТЕСТ MS4D DT2.0»**, тип — Ошибка.
> Родственная заявке 3 (потеря размеров при переносе) — если ТП предпочитает объединить, это один сценарий.

**Тема:**

```
DT – Linux – мнемосхемы – перетаскивание объекта на мнемосхему: у вставленных элементов нет Designer.Layout.Width/Height, при изменении размера редактор застревает
```

**Версия ПО:** `1.3.10.33235 (2.0.4_RC_20260622.1)`.
**ОС (стенд):** `Astra Linux Special Edition 1.8.6` («Воронеж», KVM/QEMU, virtio-vga + Spice).
**Хранилище:** PostgreSQL 16, проект «Быстрый старт» (`ms4d_project_2`).

**Описание задачи.** Собираем мнемосхему насосной станции: переносим на неё объекты (экземпляры
насосов) и выставляем им размеры, чтобы они занимали место на схеме.

**Шаги воспроизведения.**

1. Открыть `Объекты → Насосная станция → Ресурсы → Окна → Мнемосхема` (Id 49150).
2. Перетащить из дерева на холст первый объект/окно (у нас — «Окно 1» из типа «Насос 1»).
3. Перетащить так же второй и третий объекты (в нашем проекте — «Насос 2», «Насос 3»).
4. Попробовать задать/поправить размеры элементов (перетаскиванием рамки и через «Свойства → Расположение»).
5. `Проект → Сохранить`.

**Ожидаемый результат.** Каждый вставленный на мнемосхему элемент имеет свои `Designer.Layout.X/Y/Width/Height`,
их можно менять и они сохраняются в проекте.

**Фактический результат.**

1. **Вставка не пишет размеры.** Операции перетаскивания создают у элементов только `Z` и `X/Y`:
   `Designer.Layout.Width`/`Height` в этих операциях отсутствуют.
2. **У второго и третьего элементов размеров нет вообще** — ни после вставки, ни после попыток
   изменить размер: в сохранённом состоянии у них только координаты.
3. **При изменении размера редактор «застревает»**: на холсте остаются пунктирная рамка и размерные
   линии (в кадре — 350×250), изменения в модель не уходят; помогает только переключение на другую
   вкладку и обратно — и то до следующего застревания.

**Данные из хранилища (журнал операций среды, время UTC).**

| Операция | Элемент | Что записано в модель |
|---|---|---|
| trans 529 «Перетаскивание Окно 1 на `…Мнемосхема` (Id=49150)» | 54231 «Окно 1» | `Z = 5`, затем `X/Y`; `Width`/`Height` появились только после отдельной операции «Трансформация элемента» (trans 532) → 250×230 |
| trans 534 «Перетаскивание **Насос 2** на `…Мнемосхема`» | 54234 «Окно 2» | `Z = 6`, `X/Y`; далее только `X` (trans 536–538) — **`Width`/`Height` не записаны ни разу** |
| trans 539 «Перетаскивание **Насос 3** на `…Мнемосхема`» | 54237 «Окно 3» | `Z = 7`, `X/Y`; далее операции «Трансформация элемента» (trans 553–555) и серия `X/Y` (541–556) — **`Width`/`Height` не записаны ни разу** |

Текущее состояние элементов на мнемосхеме (из сохранённой модели):

```
54231 | Окно 1 | W = 250  H = 230 | X = 80  Y = 70
54234 | Окно 2 | W = -    H = -   | X = 80  Y = 340
54237 | Окно 3 | W = -    H = -   | X = 80  Y = 630
```

Дополнительно в журнале видны многократные переключения «Привязка к сетке» / «Показывать сетку»
на этой же мнемосхеме (trans 557–564) — попытки выставить положение объектов в обход застревания.

**Вложения.**

📎 Снимки модели `checkpoint.sh before/after` вокруг перетаскиваний и попыток изменения размеров
(методика — `../repro-protocol.md`, сценарий S4): в них видно, что операции в журнале есть,
а записей `Designer.Layout.Width/Height` по элементам 54234/54237 нет.
📎 Скриншот мнемосхемы с «застывшей» пунктирной рамкой и размерными линиями (350×250 при 240×220 в модели).
📎 `ErrorReports.zip` — «Сервис → Отчет об ошибках», снятый **внутри гостя Astra** (журнал среды за день).
📎 Видео: перетаскивание трёх объектов на мнемосхему и момент застревания (короткий ролик, снимаем
в окне VM).

**Замечание.** Похоже, что застревание связано с тем же механизмом, что и у заявок 2 и 3: интерфейс
принимает операцию (она появляется в журнале среды), но запись геометрии в модель не выполняется,
а редактор при этом остаётся в «незавершённом» состоянии. Смена вкладки сбрасывает это состояние.
