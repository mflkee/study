# Раскадровка видео для заявок — снимаем **в Astra** (в окне VM)

Требование ТП: видео **до 3–4 минут**, с указанием проблемных моментов по таймкодам.
Все три ролика снимаются **внутри гостя Astra** (официально поддерживаемая ОС) — с хоста пишем окно
`virt-viewer`. Дефект 4 (`systeminfo`) видео не требует: он полностью виден в журнале.

Полный порядок подготовки, страховка (снимок VM + дамп БД) и сбор артефактов —
в [`protocol-astra.md`](protocol-astra.md). Здесь только раскадровка.

| Файл | Что записываем | Длительность |
|---|---|---|
| `01-astra-crash.mp4` | окно VM: старт среды → работа → **самопроизвольное завершение** | 3–4 мин |
| `02-okno-razmer.mp4` | окно VM: «Расположение → Ширина/Высота» у окна не сохраняется | 1–1,5 мин |
| `03-ctrl-x-v.mp4` | окно VM: `Ctrl+X`/`Ctrl+V` теряет размеры элемента | 1–1,5 мин |

## Как включить запись (хост, niri)

Свой скрипт `screenrec-toggle.sh` **удалён** (2026-10-16, был визуально странный). Теперь два рабочих
пути, **оба поднимают свой `gpu-screen-recorder` — одновременно не запускать**:

**1. Оверлей `gsr-ui` по `Alt+Z`** (основной): в оверлее выбрать источник **portal** (в диалоге портала —
окно `virt-viewer` **в разделе «Окна»/«Windows»**, не «Virtual Monitor»), затем Start. Дальше
клип/повтор без диалога — включить `restorePortalSession` (gsr переиспользует restore-token
`~/.config/gpu-screen-recorder/restore_token`, окно сопоставляется по app-id + title). Для биндов:

```bash
gsr-ui-cli toggle-record-window    # старт/стоп записи окна
gsr-ui-cli toggle-show             # показать/скрыть оверлей
gsr-ui-cli status                  # идёт ли запись
```

**2. Виджет «Screen Recorder» в баре Noctalia** (плагин `screen-recorder`, правый блок): левый клик —
старт/стоп, правый — настройки (источник `portal`, fps, кодек, качество, аудио, replay, папка вывода).
IPC: `noctalia msg plugin <author/plugin:entry> plugin:screen-recorder toggle|saveReplay`.

**Если захват окна не работает** — демон поднялся до установки/смены портала:

```bash
systemctl --user restart "app-gpu\x2dscreen\x2drecorder\x2dui@autostart.service"
```

Проверка, что поток пошёл: в логе gsr строка `pipewire negotiation finished`; размер кадра = размер окна.

Файлы: gsr кладёт `~/Videos/record_<дата>_<время>.mp4`; плагин Noctalia — в папку из своих настроек.
Ролик в заявку — **до 3–4 минут**: если прогон длиннее, обрезать, например
`ffmpeg -ss 00:00:20 -t 90 -i in.mp4 -c copy out.mp4`. Обрезанный файл копируем в `evidence/attachments/`.
Альтернативы с выбором источника: `kooha`, `gpu-screen-recorder-gtk`, OBS (`Mod+Shift+O`).

## Общие правила

- Окно VM держим такого размера, чтобы читался заголовок среды с версией `1.3.10.33235`.
- Курсор — у места действия; пауза 1–2 секунды между шагами (видео смотрят без звука).
- В кадр не должны попадать пароли, почта, чужие окна.
- Версию ОС и ПО пишем в заявке текстом: в отчёте об ошибках сведений о системе нет (дефект 4).

## 01-astra-crash.mp4 — самопроизвольное завершение среды

| Таймкод | Что в кадре | Что делаем |
|---|---|---|
| 0:00–0:10 | окно VM | запись уже идёт, `virt-viewer` на переднем плане |
| 0:10–0:30 | меню Astra «Разработка» | запускаем **MasterSCADA 4D 2.0 RC** |
| 0:30–0:55 | среда | открываем проект «Быстрый старт» (видно, что хранилище PostgreSQL, проект открылся) |
| 0:55–1:30 | редактор | открываем `Насос 1 → Ресурсы → Окна → Окно 1`, подёргали элементы — среда живая |
| 1:30–… | **ожидание** | ничего не нажимаем: среда закрывается сама; фиксируем момент (окно исчезает целиком, без диалога и отчёта) |
| конец | рабочий стол Astra | окна среды нет |

В комментарии к видео: «падение на `мм:сс`, кнопки выхода никто не нажимал».
После падения — скриншот вывода с `GPU process isn't usable. Goodbye` (терминал, из которого запускали).

## 02-okno-razmer.mp4 — размер окна не сохраняется

| Таймкод | Что в кадре | Что делаем |
|---|---|---|
| 0:00–0:15 | среда | открываем `Библиотеки → Локальная → Объекты → Насос 1 → Ресурсы → Окна → Окно 1` |
| 0:15–0:35 | «Свойства → Расположение» | вводим `Ширина = 300`, `Высота = 200`, Enter; показываем, что рамка окна не изменилась |
| 0:35–0:50 | холст | тянем рамку окна мышью — видны пунктирная рамка и размерные линии, размер «отскакивает» |
| 0:50–1:05 | «Параметры → Ширина → Начальное значение» | для контраста: ставим `150`, значение **сохраняется** |
| 1:05–1:20 | `Ctrl+S` | сохраняем проект, закрываем и снова открываем проект |
| 1:20–1:35 | «Расположение» | поля Ширина/Высота окна — **пустые**; «Параметры» — по-прежнему 150 |

## 03-ctrl-x-v.mp4 — перенос элемента теряет размеры

| Таймкод | Что в кадре | Что делаем |
|---|---|---|
| 0:00–0:15 | окно со элементами | показываем элемент нормального размера и его «Расположение» (X, Y, Ширина, Высота заполнены) |
| 0:15–0:25 | выделение | `Ctrl+X` — элемент исчез |
| 0:25–0:40 | другое окно | `Ctrl+V` — элемент вставился **без размеров** (точка/пустой квадрат) |
| 0:40–1:00 | «Расположение» вставленного | `Ширина = 0`, `Высота = 0`; на мнемосхеме элемент не разглядеть |
| 1:00–1:20 | `Ctrl+S` и переоткрытие проекта | размеры так и остались нулевыми |
