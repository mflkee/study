# Упражнение 01: Диагностика по симптому

**Цель:** научиться по короткому сообщению/поведению определять слой, в котором проблема
(ОС/библиотеки, приложение, БД, права), и выбирать действие. Это навык, который экономит больше
всего времени в реальной работе.

**Как делать:** сначала ответь сам (причина + **первая** команда проверки), затем сверься с
[`../solutions/01-diagnostika.md`](../solutions/01-diagnostika.md). Ответ «переустановить» не
засчитывается.

Для каждого пункта укажи: **слой** → **причина** → **команда проверки** → **действие**.

1. `sudo apt install ./MasterSCADA4D_2.0.4_Install.deb` → `dpkg: error: cannot access archive`.
2. Приложение не стартует; в консоли `error while loading shared libraries: libXss.so.1`.
3. Запускаешь приложение второй раз — окно не открывается, а в `ps` виден процесс, запущенный вчера.
4. В консоли `The SUID sandbox helper binary was found, but is not configured correctly`, окна нет.
5. Окно открылось, но чёрное; интерфейс «тяжёлый», мышь дёргается.
6. В IDE при «Создать проект»: `Ошибка подключения: Connection refused`.
7. `password authentication failed for user "postgres"`.
8. Соединение устанавливается, но создание проекта падает с `permission denied to create database`.
9. Проект создался и работал, но после перезапуска редактора его нет в списке проектов.
10. `docker compose up -d` → `Bind for 127.0.0.1:15444 failed: port is already allocated`.
11. В консоли сыпется `fontconfig: … 48-guessfamily.conf`, но всё работает.
12. На Wayland в полях ввода приложения не переключается раскладка (клавиатурная комбинация
    вставляет пробел).

## Что сдать

Таблицу «симптом → слой → причина → проверка → действие» по всем 12 пунктам (своими словами, без
подглядывания) и **одну реально выполненную** проверку: выбери 3 любых пункта, воспроизведи симптом
и докажи вывод командами (вывод приложить).
