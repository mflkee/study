# Модуль 00: Ориентация и окружение

**Цель модуля:** получить работающий стенд и понять, из чего состоит система, — чтобы дальше
заниматься не «настройкой окружения», а самой SCADA. После модуля ты умеешь поставить DT 2.0,
запустить её, поднять PostgreSQL для проектов и пройти полный цикл «проект → логика → мнемосхема →
компиляция → эмуляция RT», а затем **тиражировать объект** и связать его с каналами ввода-вывода.

**Пререквизиты:** доступ в терминал с `sudo`, ~3 ГБ на диске под установку, ~10 ГБ под стенд БД +
проекты. Docker — только для варианта «стенд в Docker» (можно взять системный PostgreSQL).

**Время:** ~7–8 часов.

## Как проходить модуль

1. **Каждый урок заканчивается действием.** Не «прочитал», а «выполнил и предъявил вывод».
2. **Ошибки — часть урока.** В каждом уроке есть таблица «симптом → причина → действие»: сначала
   найди свой симптом там, потом гугли.
3. **Диагностика по фактам:** процессы (`ps`), лог (`sys_log`), SQL (`psql`) — а не «попробую ещё раз».
4. **Фиксируй прогресс** в [`../PROGRESS.md`](../PROGRESS.md) после модуля.
5. **Где спорно — написано `UNVERIFIED`.** Значит, проверяем на стенде и записываем факт.

## Чеклист готовности (критерии «модуль пройден»)

- [ ] Понимаю разницу DT/RT, знаю поддерживаемые ОС и почему учебный стенд может быть «вне поддержки».
- [ ] Умею разобрать `.deb` без установки (зависимости + дерево файлов).
- [ ] Среда разработки запускается; в процессах есть и Electron, и `MasterSCADA4D_Server`.
- [ ] В `sys_log` есть свежая строка `Start application …`.
- [ ] PostgreSQL поднят (системный **или** стенд в Docker), `SELECT version();` отвечает.
- [ ] В настройках среды задано подключение к БД, «Проверка подключения» проходит.
- [ ] Первый проект создан и **доказано**, что он в БД (до/после по `\l`/`\dt`).
- [ ] Урок 04 пройден: проект скомпилирован и запущен в эмуляции; `Пуск`/`Стоп` меняют значение.
- [ ] Урок 05 пройден: объект стал библиотечным типом, станция собрана из трёх **экземпляров**, каждый связан со своим `DO`-каналом; умею разорвать/переназначить связь.
- [ ] Сделана лаба «БД недоступна» (умею читать ошибку и чинить).
- [ ] Самооценка из [theory.md](theory.md) заполнена, `PROGRESS.md` обновлён.
