# Модуль 00: Ориентация и окружение

**Цели модуля:**
- Понять, как устроен курс и оценить стартовый уровень.
- Подготовить окружение: запустить среду разработки **MasterSCADA 4D DT 2.0** на Arch+niri.
- Поднять **PostgreSQL** в Docker и создать первый проект SCADA.

**Пререквизиты:** установленная среда разработки (или её `.deb`), Docker (+ compose), доступ в сеть,
~6 ГБ свободного диска (образ PostgreSQL + проекты). Умение работать в терминале.

**План:**
1. `theory.md` — карта курса, стек стенда, как учиться (конспект).
2. Урок 01: окружение и извлечение `.deb` — ~50 мин.
3. Урок 02: запуск SCADA на Arch+niri — ~50 мин.
4. Урок 03: PostgreSQL в Docker и первый проект — ~60 мин.
5. Лаба «Стенд отвечает» — ~1.5 ч.

**Оценка времени:** ~6 часов.

**Чеклист готовности (критерии «модуль пройден»):**
- [ ] Зависимости на месте (gtk3, nss, libxss, libxtst, at-spi2, libsecret, mesa, …)
- [ ] `scripts/run-masterscada.sh` поднимает среду разработки; окно видно в `niri msg`
- [ ] `docker compose up -d` в `infra/` поднимает PostgreSQL без ошибок
- [ ] `docker compose exec postgres psql -U course -d course -c "SELECT version();"` → PostgreSQL 16.x
- [ ] Создан и сохранён первый проект (в PostgreSQL)
- [ ] Лаба «Стенд отвечает» выполнена по критериям
- [ ] Самооценка заполнена (урок 03), `PROGRESS.md` обновлён

**Следующий модуль:** `01-project-basics` — структура проекта (можно начинать, когда стенд отвечает).
