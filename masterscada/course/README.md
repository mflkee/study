# Курс «MasterSCADA 4D 2.0 для СИКН»

Практический курс для самостоятельного обучения: от запуска среды разработки и первого проекта
до полноценного учебного стенда — теги и объекты, программы FBD/ST, визуализация HMI, каналы и
протоколы (Modbus/OPC UA), **архивы в PostgreSQL**, тревоги, развёртывание среды исполнения (RT),
резервирование и ИБ. Сквозная предметная область — **СИКН** (система измерений количества и
качества нефти), как в курсе по PostgreSQL.

> Окружение: **Arch Linux + niri/Wayland**, среда разработки **MasterSCADA 4D DT 2.0** в `/opt/MasterSCADA 4D 2.0`,
> PostgreSQL — в Docker. Запуск проверен (см. [`../docs/reference/ustanovka-arch-niri.md`](../docs/reference/ustanovka-arch-niri.md)).

## Как устроен курс

- **14 модулей** (`00-orientation` … `13-interview-prep`), строго по порядку: каждый опирается на предыдущие.
- Единая структура модуля: `README.md` (цели и чеклист), `theory.md` (конспект),
  `lessons/` (пошаговые уроки), `examples/` (рабочие примеры и проекты SCADA),
  `exercises/` (задания, решения в `solutions/`), `labs/` (длинные практики и «сломай и почини»).
- Соотношение **30% чтения / 70% практики**: каждый урок заканчивается заданием.
- Стенд: среда разработки + PostgreSQL в Docker (`course/00-orientation/infra/`).
- **Факты — только из справки вендора.** Где утверждение не проверено на стенде — помечается `UNVERIFIED`.
- Решения и примеры — это **проекты SCADA** (файлы/экспорт проектов), а не только текст.

## Как начать

1. Прочитай [`00-orientation/README.md`](00-orientation/README.md).
2. Убедись, что среда разработки запускается: `../scripts/run-masterscada.sh`.
3. Подними PostgreSQL: `cd 00-orientation/infra && docker compose up -d`.
4. Пройди модуль 00, отмечай прогресс в [`PROGRESS.md`](PROGRESS.md).

Документация (онлайн-справка и конспекты) — в [`../docs/`](../docs/); правила для ИИ — в
[`../AGENTS.md`](../AGENTS.md).
