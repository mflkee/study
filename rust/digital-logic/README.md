# digital-logic — цифровая логика на Rust

Мини-курс на один вечер: от булевых гейтов до регистров, всё своими руками.
Теория — в `LECTURE.md` каждой ступени, задание — `task.rs`, разбор — `answer.rs`.

## Как проходить

1. Читаешь `stepN-*/LECTURE.md`.
2. Открываешь `stepN-*/task.rs` и заменяешь `todo!()` своей реализацией.
3. Запускаешь: `cargo run --bin step1-task` (тесты: `cargo test --bin step1-task`).
4. Сверяешься: `cargo run --bin step1-answer`.

Из корня `digital-logic`:

```bash
cargo run  --bin step1-task      # твоя попытка
cargo test --bin step1-task      # самопроверка тестами
cargo run  --bin step1-answer    # разбор
```

## Ступени

| # | Тема | Что осваиваешь |
|---|------|----------------|
| 1 | Гейты и таблицы истинности | `bool`-операции, функция как значение, композиция гейтов |
| 2 | Битовые операции на `u8` | сдвиги, маски, «гейт на 8 линий сразу» |
| 3 | Сумматор из гейтов | полусумматор → полный сумматор → 8-битный ripple-carry |
| 4 | Триггеры и регистры | состояние: `struct` + `impl` + `&mut self` |

## Тренажёр (`drills/`)

К каждой ступени — отдельный тренажёр: 60 коротких упражнений, у каждого свой
тест, блоки проверяются по отдельности.

```bash
cargo test --bin step1-drills     # прогресс (красное тает по мере решений)
cargo run  --bin step1-drills     # карта упражнений
cargo test --bin step2-drills     # и так далее: step3-drills, step4-drills
cargo run  --bin step1-drills-answer   # разбор тренажёра, если застрял
```

| Бинарник | Упражнений | Тестов | Тема |
|---|---|---|---|
| `step1-drills` | 17 | 18 | гейты, NAND-полнота, три входа, мультиплексор |
| `step2-drills` | 19 | 19 | бит, нибблы, маски, чётность, разворот битов |
| `step3-drills` | 14 | 14 | полусумматор → adder16, вычитание |
| `step4-drills` | 10 | 11 | триггеры, счётчик, кольцевой сдвиг, импульсы |

Разборы — те же бинарники с суффиксом `-answer` (`step1-drills-answer` …):
те же решения, те же тесты, но зелёные, плюс демо-вывод в `main`.

Подробности и как читать вывод — `drills/README.md`.

## Что дальше (если останется время)

- **Гейт как данные**: описать вентили `enum Gate { And, Or, Xor, Nand }` и
  симулировать схему как граф. Тогда устройство — это данные, а не функция.
- **NAND-полнота**: собрать вообще всё только из `nand`.
- **Мультиплексор / декодер**: выбор одного из входов по управляющим битам.
- **Счётчик / сдвиговый регистр**: устройства с памятью посложнее.
