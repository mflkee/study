# Тренажёр: 60 упражнений на все 4 ступени

Здесь то же самое, что в ступенях, но много раз и мелкими шагами. Смысл — не
«пройти задание», а **набить руку**: один приём повторяется 5–19 раз в разных
обличьях, пока не станет автоматическим.

## Как запускать

```bash
cargo test --bin step1-drills     # прогресс по ступени 1 (и так далее)
cargo run  --bin step1-drills     # карта: какие блоки и упражнения внутри
```

Запускай тесты **после каждого упражнения** — сделанное сразу станет зелёным:

```
failures:
    block1_gates::drill_nand
    block1_gates::drill_nor
    ...
test result: FAILED. 0 passed; 18 failed
```

Реализовал `nand` → перезапустил → в списке падений его больше нет. Это и есть
«щелкать»: список красного тает, пока не станет пусто.

Если хочется видеть имена всех тестов, не запуская:
`cargo test --bin step1-drills -- --list`.

## Что внутри

| Бинарник | Ступень | Упражнений | Тестов | Блоки |
|---|---|---|---|---|
| `step1-drills` | 1. Гейты | 17 | 18 | 1) гейты и их смыслы 2) собрать из NAND 3) три входа 4) выбор и функции как значения |
| `step2-drills` | 2. Биты на `u8` | 19 | 19 | 1) один бит 2) нибблы и маски 3) счёт и поиск 4) байт целиком |
| `step3-drills` | 3. Сумматоры | 14 | 14 | 1) слагаемые 2) многоразрядные 3) применение |
| `step4-drills` | 4. Триггеры | 10 | 11 | 1) триггеры 2) регистры 3) применение |

Тесты внутри блока **независимы**: блоки можно делать в любом порядке, и даже
внутри блока — как удобно.

## Как это устроено

- Одно упражнение = одна функция + один тест. Тебе нужно написать **только тело
  функции**, всё остальное готово.
- В теле стоит `todo!("короткая подсказка")`. Это заглушка: она говорит
  компилятору «здесь будет значение нужного типа, пока не трогай», а во время
  теста паникует — поэтому тест и красный. Как только написал свою реализацию,
  ты `todo!()` **удаляешь** (заменяешь телом).
- Тесты написаны так, чтобы не зависеть от твоих других функций: например,
  `drill_truth_table_rows` передаёт гейты замыканиями, а не вызывает соседние
  упражнения. Значит, порядок прохождения свободный.

## Чего тут нет

Готовых разборов (как `stepN-answer` для ступеней) здесь нет — эталон как раз
и есть тесты: если все зелёные, всё верно. Если совсем застрял — скажи, разберём.

## Связь со ступенями

Теория и объяснения — в `stepN-*/LECTURE.md`. Если упражнение не идёт, смотри
соответствующий раздел лекции; в тренажёре теории нет, только формулировки.
