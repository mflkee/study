# Задание 6. Приложение для отслеживания расходов

## Описание

Приложение для управления личными финансами, позволяющее пользователям фиксировать доходы и расходы и получать аналитику по ним.

---

## Основные функции

- **Добавление финансовых транзакций** (доходов и расходов) с указанием категории.
- **Просмотр аналитики** с группировкой по категориям и временным периодам.
- **Визуализация данных** в виде графиков, например круговая диаграмма расходов.
- **Сортировка транзакций** по дате и категории.

---

## ИИ-функции

- Добавить учёт доходов.
- Добавить персональные финансовые рекомендации на основе доходов и расходов пользователя.

---

## Дополнительные функции

- Экспорт данных в файлы формата `.csv` или `.xlsx`.
- Напоминания о регулярных платежах.

---

## Требования к бэкенду

### 1. Модель данных (основные функции)

Минимальный набор таблиц:

| Таблица | Поля |
|---------|------|
| **Транзакция** | идентификатор, наименование, тип (доход или расход), категория, сумма, дата, ссылка на пользователя |
| **Группа** | идентификатор группы, название группы, ссылка на пользователя |

> Таблица `группа` позволяет объединить пользователей в группы, например для учёта семейных транзакций.

### 2. Модель данных (регистрация, авторизация и аутентификация)

| Поле |
|------|
| идентификатор |
| имя |
| фамилия |
| логин |
| пароль |

### 3. API для регистрации, авторизации и аутентификации

| Эндпоинт | Описание |
|----------|----------|
| Регистрация | Создание нового пользователя |
| Аутентификация | Вход в систему |
| Смена пароля | Изменение текущего пароля |
| Обновление токена | Получение нового access-токена |

### 4. API для работы с транзакциями

| Метод | Описание |
|-------|----------|
| Создание | Добавление новой транзакции |
| Удаление | Удаление существующей транзакции |
| Редактирование | Изменение данных транзакции |
| Чтение | Получение списка транзакций с пагинацией, фильтрами по категории и дате |

### 5. API для работы с группами

| Метод | Описание |
|-------|----------|
| Создание | Создание новой группы |
| Удаление | Удаление группы |
| Редактирование | Изменение данных группы |
| Чтение | Получение информации о группе |
| Аналитика по группам | Получение аналитических данных по группе |

## Результат реализации бэкенда

1. **Модель данных и миграции** — разработана модель данных и настроены миграции.
2. **API основных функций** — создан API для работы с основными функциями. Код запускается и выполняет требования задания. Допускается и приветствуется любое расширение, дополнение и обоснованное улучшение функционала.
3. **Набор тестов** — разработан набор тестов для проверки всех эндпоинтов API.
4. **Развёртывание** — создан файл конфигурации Docker Compose для сборки и запуска проекта в контейнере.
