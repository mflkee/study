2. Предобработка и разбиение¶

ColumnTransformer: числовые признаки → StandardScaler, категориальные → OneHotEncoder. Разбиение 80/20 со stratify=y и random_state=42 — ровно как в Практике 1.

In [4]:
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, random_state=RANDOM_STATE, stratify=y
)
print("train:", X_train.shape, " test:", X_test.shape)

num_cols = X_train.select_dtypes(include=np.number).columns.tolist()
cat_cols = X_train.select_dtypes(exclude=np.number).columns.tolist()

preprocessor = ColumnTransformer(
    transformers=[
        ("num", StandardScaler(), num_cols),
        ("cat", OneHotEncoder(handle_unknown="ignore"), cat_cols),
    ]
)

train: (5634, 19)  test: (1409, 19)

3. LogisticRegression — базовая модель (из Практики 1)¶

Оставляем её в ноутбуке, чтобы сравнение шло на одном и том же разбиении, а не с цифрами из прошлой работы.

In [5]:
log_reg = Pipeline([
    ("prep", preprocessor),
    ("model", LogisticRegression(max_iter=1000, random_state=RANDOM_STATE)),
])
log_reg.fit(X_train, y_train)

pred_lr = log_reg.predict(X_test)
prob_lr = log_reg.predict_proba(X_test)[:, 1]

print(classification_report(y_test, pred_lr, digits=3, target_names=["остался", "ушёл"]))
print(f"ROC-AUC (LogisticRegression): {roc_auc_score(y_test, prob_lr):.3f}")

4. CatBoost — замена модели¶

Меняем только последний шаг пайплайна: LogisticRegression → CatBoostClassifier. Параметры скромные (100 итераций, verbose=0), чтобы ноутбук считался за секунды на CPU и без GPU.

In [6]:
catboost = Pipeline([
    ("prep", preprocessor),
    ("model", CatBoostClassifier(
        iterations=100,
        depth=4,
        learning_rate=0.1,
        loss_function="Logloss",
        eval_metric="AUC",
        random_seed=RANDOM_STATE,
        verbose=0,
    )),
])
catboost.fit(X_train, y_train)

pred_cb = catboost.predict(X_test).ravel()
prob_cb = catboost.predict_proba(X_test)[:, 1]

print(classification_report(y_test, pred_cb, digits=3, target_names=["остался", "ушёл"]))

6. Важность признаков¶

feature_importances_ у CatBoost считается по вкладу признака в разбиения деревьев. Имена берём из ColumnTransformer, чтобы видеть исходные признаки, а не индексы колонок.

In [9]:
model = catboost.named_steps["model"]
feature_names = catboost.named_steps["prep"].get_feature_names_out()

importance = (
    pd.Series(model.get_feature_importance(), index=feature_names)
    .sort_values(ascending=False)
    .head(15)
    .rename("Важность")
    .to_frame()
)
importance.index = importance.index.str.replace(r"^(num|cat)__", "", regex=True)

7. Выводы¶

  1. Замена модели — один шаг пайплайна. Предобработка, разбиение и метрики остаются прежними; меняется только оценщик, поэтому сравнение корректное.
  2. CatBoost vs LogisticRegression — измеримый, но небольшой выигрыш по ранжированию: ROC-AUC 0.846 против 0.842, при этом по F1 для класса «ушёл» CatBoost чуть проигрывает (0.588 против 0.604) — он осторожнее в положительном классе (recall ниже: 0.527 против 0.559). Причина в природе данных: 7043 строки, много категориальных признаков, слабые нелинейности — сигнал в основном аддитивный, поэтому LogisticRegression на хорошо закодированных признаках остаётся сильным baseline.
  3. Практический вывод. Для табличных данных с категориями CatBoost выигрывает не только метрикой, но и тем, что умеет работать с категориями «из коробки» (cat_features без One-Hot) — в этом ноутбуке OHE сохранён намеренно, чтобы отличалась ровно одна строка кода, как требует задание.
  4. Главные факторы — тип контракта (Contract_Month-to-month), стаж (tenure) и размер ежемесячного платежа: это согласуется с выводами Практики 1.
