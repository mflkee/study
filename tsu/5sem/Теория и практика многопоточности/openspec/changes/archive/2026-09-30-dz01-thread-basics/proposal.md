# Proposal

## Why

ДЗ 1 (дедлайн 09.09.2026) — вводное задание курса: оно требует не только потоки, но и **проектирование архитектуры итогового приложения** и создание каркаса проекта на Spring Boot. Без этого каркаса остальные семь домашних заданий придётся реализовывать как разрозненные консольные демо, а Итоговое ДЗ (вариант 3 — парсер вакансий) начинать с нуля. Сейчас в репозитории лежит только `lesson1/HelloWorld.java` — отправная точка для всего остального.

## What Changes

- Создаётся Maven-проект `app/` (Spring Boot 4.1.x, `--release 21`) с пакетом `ru.tsu.tpm.vacancyparser` — каркас Итогового ДЗ (вариант 3, парсер вакансий).
- Реализуется сервисный слой и класс задачи с двумя способами создания потоков: наследование `Thread` и реализация `Runnable`.
- Потоки получают осмысленные имена (`CounterWorker`, `LoggerThread`) и порядковый номер, оба выводятся при работе.
- Выводится список всех активных потоков приложения.
- Демо запускается изолированно через `--app.hw=hw01`, не требуя ручной настройки.
- Пишется отчёт `Домашнее задание 1 (дедлайн 09.09.2026)/README.md` по чек-листу самопроверки.

## Capabilities

### New Capabilities
- `dz01-thread-basics`: каркас Spring Boot-приложения и демонстрация базовых способов создания, именования и инвентаризации потоков.

### Modified Capabilities

_Пусто — это первое изменение, существующих спецификаций в проекте нет._

## Impact

- **Новый код**: `app/pom.xml`, `app/src/main/java/ru/tsu/tpm/vacancyparser/**`, `app/src/test/java/**`.
- **Новые зависимости**: `spring-boot-starter-web`, `spring-boot-starter-test` (JUnit 5).
- **Новый артефакт**: `Домашнее задание 1 (дедлайн 09.09.2026)/README.md`.
- **Прямые последствия**: `app/` становится общей базой для ДЗ 2–8 — структура модулей, соглашение о запуске демо и пакет `common` фиксируются здесь и переиспользуются дальше.
- **Вне scope**: наполнение домена парсера вакансий, H2, `@Scheduled` — это Итоговое ДЗ (дедлайн 08.11.2026), оно планируется отдельно.
