## Описание задания

По списку идентификаторов (ID товаров, коды валют, названия городов, номера счетов и т.п.) получите
данные из внешнего источника (API, БД, файл, парсер). Реализуйте метод, который:

- асинхронно через `CompletableFuture` получает данные по каждому идентификатору;
- для каждого результата применяет преобразование;
- объединяет два независимых асинхронных результата в один объект;
- возвращает список итоговых объектов, собранных параллельно.

Используйте `thenCombine`, `thenApply`, `thenAccept`.

Реализуйте метод `public List<FinalResult> fetchAllDataAsync(List<String> ids)`.

**Вторая часть:**

- обработка ошибок через `handle`/`exceptionally`, чтобы сбой одной задачи не ломал всю операцию;
- собственный `Executor` (не `ForkJoinPool.commonPool`) для всех асинхронных вызовов;
- пул с именованными демон-потоками и разумным размером;
- `thenApplyAsync(…, executor)` для тяжёлых преобразований;
- корректное завершение `ExecutorService` при остановке приложения;
- логирование с именем потока и ID запроса;
- имитировать ошибку в одном источнике — метод должен вернуть частичный результат;
- сравнить время асинхронной и синхронной версий.

**Отчёт:** описание этапов, промежуточные результаты, выводы.

## Что сделано

Пакет `hw10.completable`: два независимых источника (данные вакансии и справочник компаний) на
локальной HTTP-заглушке, конвейер `CompletableFuture` на собственном пуле именованных демон-потоков,
изоляция сбоев через `handle` и `exceptionally`, синхронная версия для сравнения времени.
