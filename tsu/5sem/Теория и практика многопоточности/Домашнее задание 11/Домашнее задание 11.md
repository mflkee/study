Отчёт с этапами.

## Что сделано

Пакет `hw11.forkjoin`: детерминированный набор агрегированных вакансий (имитация накопленных
результатов парсера), рекурсивная `BatchCountTask` с разбиением **по границам партий** (листьев ровно
`ceil(size / batchSize)`), собственный `ForkJoinPool` с именованными потоками, последовательная база
сравнения и таблица замеров по размеру партии и параллелизму.

Подробный отчёт с фактическими числами — в файле `Домашнее задание 11/README.md`.

### Запуск

```bash
cd "Теория и практика многопоточности"
mvn -pl app spring-boot:run -Dspring-boot.run.arguments="--app.hw=hw11 --server.port=0"
```

Настройки (`app.hw11.*`) меняются аргументами без правки кода, например
`--app.hw11.dataset-size=2000000 --app.hw11.batch-size=10000`.
