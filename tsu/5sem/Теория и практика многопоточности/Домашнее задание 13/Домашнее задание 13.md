## Описание задания

Реализовать функционал с `BlockingQueue` для передачи задач между производителями и потребителями:
сервер задач, несколько producer'ов кладут URL в очередь, consumer'ы берут и обрабатывают (скачивают
страницу и извлекают заголовок).

Отчёт с этапами.

## Что сделано

Пакет `hw13.queue`: ограниченная очередь задач (`LinkedBlockingQueue` с «таблетками» остановки),
несколько производителей, несколько потребителей, скачивание страниц с локального сайта-заглушки и
извлечение `<title>`, счётчики обратного давления (глубина очереди, блокировки `put`) и проверка
отсутствия потерь и повторов.

Подробный отчёт с фактическими числами — в файле `Домашнее задание 13/README.md`.

### Запуск

```bash
cd "Теория и практика многопоточности"
mvn -pl app spring-boot:run -Dspring-boot.run.arguments="--app.hw=hw13 --server.port=0"
```

Настройки (`app.hw13.*`) меняются аргументами без правки кода, например
`--app.hw13.pages=60 --app.hw13.consumers=6 --app.hw13.queue-capacity=8`.
