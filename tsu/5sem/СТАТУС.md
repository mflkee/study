### Итоговое ДЗ — сделано (18.10.2026)

Пакет `app/src/main/java/ru/tsu/tpm/vacancyparser/finaltask/` + инструкция
`ИТОГОВОЕ_ДЗ_README.md`:

| Требование | Реализация |
|---|---|
| Spring Boot MVC | `FinalTaskController`, слой service/repo |
| «Нажать пуск» без настроек | при старте сам поднимает локальный HTTP-источник с 12 вакансиями и делает первый обход |
| Кастомный `ExecutorService` | `ThreadPoolExecutor` (4 потока `final-crawl-N`, ограниченная очередь, `CallerRunsPolicy`) |
| Планировщик | `@Scheduled(fixedDelayString=...)`, по умолчанию каждые 20 с |
| H2 | файловая БД `app/data/finaltask.mv.db`, `ddl-auto=update` |
| Эндпоинт результатов | `GET /final/answer` (пагинация, фильтры, сортировка), `GET /final/stats` |
| `parallelStream()` по данным из H2 | `VacancyQueryService` |
| Межсервисное взаимодействие | `RestTemplate` с таймаутами (обоснование в README) |
| Потокобезопасные структуры | `LinkedBlockingQueue`, `ConcurrentHashMap`, `CopyOnWriteArrayList`, `AtomicLong`, `ReentrantLock` |
| Офлайн-проверка | локальная заглушка + приём готового HTML/вакансии по `POST /final/posts` |
