# Защита ФМС — что открывать

Тема 7. «Действия после получения патента». Команда: Малышева Елена, Макеев Глеб.
Материалы: <https://github.com/mflkee/fms-course>

## Файлы

| Файл | Когда открывать |
|---|---|
| **`ФМС — слайды.pdf`** | **Во время защиты.** 20 слайдов 16:9, листаются стрелками в полноэкранном режиме (в Okular/Evince — `Ctrl+Shift+F`) |
| **`ФМС — что говорить.pdf`** | **Рядом с собой.** Речь на 8 минут по слайдам, разбор демонстрации, 20 ответов на вопросы |
| **`ФМС — все диаграммы.pdf`** | 23 диаграммы по одной на страницу, с оглавлением и закладками — если попросят показать конкретную |
| **`диаграммы/`** | те же 23 диаграммы отдельными PNG (200 dpi), разложены по лабораторным; индекс — `диаграммы/README.md` |
| **`ФМС — шпаргалка.pdf`** | **Держать под рукой.** 2 страницы A4: вопрос → короткий ответ, по блокам |
| `ФМС — книжка для подготовки.pdf` | Для подготовки: пояснения, «что сказать», разбор одной операции |
| `ФМС — отчёт.pdf` | Официальный отчёт по лабораторным, если попросят файл |

## Порядок

1. Открыть `ФМС — слайды.pdf` на весь экран — первый слайд на экране.
2. Открыть `ФМС — что говорить.pdf` на втором мониторе или телефоне.
3. Терминал: `cd ~/projects/study/tsu/5sem/Функциональное моделирование систем/fms-course/lab6-implementation` → `uvicorn app.main:app --port 8099`.
4. Вкладки: GitHub `fms-course`, Swagger `127.0.0.1:8099/docs`.

Демо идёт по слайду 20, но показывается в терминале; речь к нему — во второй половине
`ФМС — что говорить.pdf`.

## Диаграммы

```
диаграммы/
├── 1-прецеденты/           1 файл
├── 2-модель/               1 файл
├── 3-последовательности/   8 файлов (4 сценария + 4 альтернативы)
├── 4-коммуникации/        10 файлов (по одной на операцию)
└── 5-классы/               3 файла
```

Файлы названы по-русски и пронумерованы: `05 — П03 Уведомление МВД — основной сценарий (ЕПГУ).png`.
Источник — `.puml` из репозитория `fms-course`, рендер 200 dpi (`PLANTUML_LIMIT_SIZE=20000`).

## Пересборка

Исходники — в `../_архив/`:

```bash
cd "../_архив/слайды" && uvx weasyprint slides.html "../../защита/ФМС — слайды.pdf"
cd "../_архив/речь"   && uvx weasyprint speech.html "../../защита/ФМС — что говорить.pdf"
cd "../_архив/книга"  && uvx weasyprint book.html   "../../защита/ФМС — книжка для подготовки.pdf"
```

Проверка: слайды — 20 страниц 960×540 pt, речь — 11 страниц A4,
книжка — 18 страниц A4, все диаграммы — 24 страницы A4 landscape.
