# Защита ФМС — что открывать

Тема 7. «Действия после получения патента». Команда: Малышева Елена, Макеев Глеб.
Материалы: <https://github.com/mflkee/fms-course>

## Три файла

| Файл | Когда открывать |
|---|---|
| **`ФМС — слайды.pdf`** | **Во время защиты.** 22 слайда 16:9, листаются стрелками в полноэкранном режиме (в Okular/Evince — `Ctrl+Shift+F`) |
| **`ФМС — что говорить.pdf`** | **Рядом с собой.** Речь на 8 минут по слайдам, разбор демонстрации, 20 ответов на вопросы |
| `ФМС — книжка для подготовки.pdf` | Для подготовки: пояснения, «что сказать», разбор одной операции |
| `ФМС — отчёт.pdf` | Официальный отчёт по лабораторным, если попросят файл |

## Порядок

1. Открыть `ФМС — слайды.pdf` на весь экран — первый слайд на экране.
2. Открыть `ФМС — что говорить.pdf` на втором мониторе или телефоне.
3. Терминал: `cd ~/projects/fms-course/lab6-implementation` → `uvicorn app.main:app --port 8099`.
4. Вкладки: GitHub `fms-course`, Swagger `127.0.0.1:8099/docs`.

Демо идёт по слайду 20, но показывается в терминале; речь к нему — во второй половине
`ФМС — что говорить.pdf`.

## Пересборка

Исходники лежат в `../_архив/` (вне репозитория курса, чтобы не мешать сдаче):

```bash
cd "../_архив/слайды" && uvx weasyprint slides.html "../../защита/ФМС — слайды.pdf"
cd "../_архив/речь"   && uvx weasyprint speech.html "../../защита/ФМС — что говорить.pdf"
cd "../_архив/книга"  && uvx weasyprint book.html   "../../защита/ФМС — книжка для подготовки.pdf"
```

Проверка: слайды — 22 страницы 960×540 pt, речь — 11 страниц A4,
книжка — 18 страниц A4.
