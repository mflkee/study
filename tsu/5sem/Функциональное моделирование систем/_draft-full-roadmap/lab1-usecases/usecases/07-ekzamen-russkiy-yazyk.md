# П07. Подтверждение владения русским языком, знания истории и основ законодательства

| Поле | Значение |
|---|---|
| **Название** | Подтверждение владения русским языком, знания истории России и основ законодательства РФ |
| **Рамки** | Система «Дорожная карта миграционного учёта» |
| **Уровень** | Задача пользователя (пользовательский прецедент) |
| **Основной исполнитель** | Иностранный гражданин (A1) |
| **Участники** | Иностранный гражданин; образовательная организация — центр тестирования (A10); сотрудник ОВМ МВД (A4) |
| **Связанные прецеденты** | Включается в П08, П10, П11 |

## Заинтересованные лица и их интересы

| Лицо | Интерес |
|---|---|
| Иностранный гражданин | Получить сертификат с первой попытки, не переплачивать за пересдачи, уложиться в срок до подачи заявления |
| Образовательная организация | Экзамен проведён по регламенту, результат внесён в реестр |
| Сотрудник ОВМ МВД | Сертификат подлинный, действующий и найден в реестре |
| Работодатель | Работник соответствует языковым требованиям для допуска к работе |

## Предусловия

- Профиль ИГ создан (П01); определено, что документ требуется: для граждан Азербайджана, Таджикистана, Узбекистана, Молдовы и Украины при оформлении патента (а также для РВП/ВНЖ по требованиям справочника).
- У ИГ нет основания освобождения: документ об образовании, подтверждающий владение русским языком, аттестат, полученный до 1991 года, либо диплом, полученный на территории РФ.
- В справочнике указаны уполномоченные образовательные организации и состав экзамена (русский язык, история России, основы законодательства РФ).

## Постусловия

- Экзамен сдан по всем модулям; сертификат получен и внесён в реестр.
- В деле ИГ сохранены реквизиты сертификата (номер, дата, организация, срок действия) и скан-копия.
- Шаг закрыт в карте; требование в П08 / П10 / П11 снято; запланировано напоминание об истечении срока действия сертификата.

## Основной успешный сценарий

| № | Действия исполнителя | Отклик системы |
|---|---|---|
| 1 | ИГ открывает шаг «Подтверждение владения русским языком» | Система проверяет, требуется ли документ в его случае, и указывает основание требования или освобождения |
| 2 | ИГ выбирает образовательную организацию и дату экзамена | Система показывает уполномоченные организации, стоимость, состав экзамена и свободные даты |
| 3 | ИГ записывается и оплачивает экзамен | Система фиксирует запись и передаёт сведения организации |
| 4 | ИГ сдаёт экзамен (русский язык, история, основы законодательства) | Система получает результат по каждому модулю |
| 5 | | При успехе Система фиксирует результат и ожидает выпуска сертификата |
| 6 | ИГ получает сертификат и загружает его | Система проверяет сертификат по реестру, сохраняет реквизиты, закрывает шаг |
| 7 | | Система снимает требование в зависимых прецедентах и планирует напоминание о сроке действия сертификата |

## Альтернативные сценарии

**1а. Есть основание освобождения.**
1. ИГ указывает документ (аттестат до 1991 года, диплом РФ, документ об образовании, подтверждающий владение русским языком).
2. Система проверяет документ и исключает шаг из карты с указанием основания.

**4а. Один из модулей не сдан.**
1. Система фиксирует, какой модуль не сдан, и показывает порядок пересдачи и сроки.
2. Шаг остаётся открытым; зависимые прецеденты блокируются; ИГ получает предупреждение о влиянии на срок подачи на патент.

**6а. Сертификат не найден в реестре.**
1. Система не принимает документ и указывает причину.
2. ИГ обращается в образовательную организацию; до подтверждения шаг остаётся открытым.

**6б. Данные в сертификате не совпадают с паспортом.**
1. Система показывает расхождение и требует замены сертификата.
2. Зависимые прецеденты блокируются до устранения.

**\*а. Срок действия сертификата истекает до подачи заявления.**
1. Система предупреждает ИГ и предлагает повторную сдачу.
2. Новый сертификат замещает предыдущий в зависимых прецедентах.

## Специальные требования

- Проверка сертификата по реестру обязательна: без неё шаг не закрывается (защита от подделок).
- Результаты экзамена и сертификат хранятся в деле не менее срока действия сертификата.

## Частота использования

Однократно, далее — по истечении срока действия сертификата.

## Открытые вопросы

- Нужно ли выделять экзамен и получение сертификата в два прецедента (сейчас — один, по критерию ЕБР: результат один — действующий сертификат)?
- Как учитывать сертификат, выданный в другом регионе, — действует ли он без ограничений?
- Требуется ли отдельная проверка знания языка для ВНЖ сверх сертификата для патента?
