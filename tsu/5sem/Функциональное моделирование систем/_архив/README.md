## Куда переехали диаграммы

23 диаграммы раньше лежали здесь (`_архив/diagrams/`) как «экранные» копии из репозитория —
на A4 они были нечитаемы (шрифт 2–3 pt). Теперь они пересобраны из исходников `.puml`
в **200 dpi** и лежат в `../защита/диаграммы/` по лабораторным, с русскими именами.
Там же галерея `../защита/ФМС — все диаграммы.pdf` — 23 диаграммы по одной на страницу.

## Пересборка документов

Диаграммы (нужны только если правились `.puml`; исходники — в `~/projects/study/tsu/5sem/Функциональное моделирование систем/fms-course`):

```bash
cd "5sem/Функциональное моделирование систем/_архив/книга"
plantuml -tpng -Sdpi=300 -o ../img src/*.puml
```

Документы — из папки каждого исходника:

```bash
cd _архив/слайды && uvx weasyprint slides.html "../../защита/ФМС — слайды.pdf"
cd _архив/речь   && uvx weasyprint speech.html "../../защита/ФМС — что говорить.pdf"
cd _архив/книга  && uvx weasyprint book.html   "../../защита/ФМС — книжка для подготовки.pdf"
cd _архив/книга  && uvx weasyprint report.html "../../защита/ФМС — отчёт.pdf"
```

Диаграммы и галерея (если в `fms-course` правились `.puml`):

```bash
cd _архив/скрипты && python3 build_diagrams.py && python3 build_gallery.py
```

Проверка: `pdfinfo "... | grep Pages` → слайды 20 (960×540 pt), речь 11, отчёт 16, книжка 17, шпаргалка 2, все диаграммы 24.

## Почему диаграммы перерисованы

Исходные диаграммы в репозитории рассчитаны на экран: при печати на A4 шрифт получается 2–3 pt,
линии сливаются. В книжке и на слайдах — упрощённые версии крупным шрифтом (20 pt),
в подписях указано, что полные диаграммы есть в репозитории `github.com/mflkee/fms-course`.
