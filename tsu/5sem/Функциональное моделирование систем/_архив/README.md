# Архив по ФМС

Всё, что не нужно печатать, лежит здесь. В `../защита/` два готовых PDF:

- `ФМС — отчёт.pdf` — чистовой отчёт по лабораторным работам, 16 страниц: титул, содержание,
  постановка задачи, шесть работ, трассировка, проектные решения, заключение. **Этот файл показывать на экране.**
- `ФМС — книжка для подготовки.pdf` — учебная книжка на 18 страниц: больше пояснений, «что сказать»,
  вопросы с ответами. Для подготовки, не для показа.

| Что | Зачем хранится |
|---|---|
| `книга/` | исходники книжки: `book.html`, `book.css`, `src/*.puml`, `img/*.png` (300 dpi) |
| `diagrams/` | 42 файла диаграмм из репозитория — те самые, которые на А4 нечитаемы (шрифт 2–3 pt) |
| `ФМС — подготовка к защите.md` / `.pdf` | полная версия «на отлично»: 35 диаграмм, контракты всех операций |
| `ФМС — шпаргалка на защиту.md` / `.pdf` | старая шпаргалка (заменена книжкой) |
| `ФМС — план ознакомления.md` | план подготовки на день |

## Пересборка документов

```bash
cd "5sem/Функциональное моделирование систем/_архив/книга"
plantuml -tpng -Sdpi=300 -o ../img src/*.puml

uvx weasyprint report.html "../../защита/ФМС — отчёт.pdf"
uvx weasyprint book.html   "../../защита/ФМС — книжка для подготовки.pdf"
```

Проверка: `pdfinfo "... | grep Pages` → отчёт 16, книжка 18.

## Почему диаграммы перерисованы

Исходные диаграммы (`diagrams/`) рассчитаны на экран: при печати на A4 шрифт получается 2–3 pt,
линии сливаются. В книжке — упрощённые версии крупным шрифтом, в подписях указано,
что полные диаграммы есть в репозитории `github.com/mflkee/fms-course`.
