# Архив по ФМС

Всё, что не нужно печатать, лежит здесь. В `../защита/` четыре готовых PDF:

- **`ФМС — слайды.pdf`** — 22 слайда 16:9 для показа **во время защиты**: рамки темы, шесть
  лабораторных, 10 диаграмм, цифры, трассировка, демо. Листается стрелками.
- **`ФМС — что говорить.pdf`** — речь на 8 минут по этим слайдам, разбор демонстрации,
  20 коротких ответов на вопросы, карта «что открыть». Читается с листа, 11 страниц A4.
- `ФМС — отчёт.pdf` — чистовой отчёт по лабораторным, 16 страниц. Показать, если попросят файл.
- `ФМС — книжка для подготовки.pdf` — учебная книжка на 18 страниц: больше пояснений,
  «что сказать», вопросы с ответами. Для подготовки, не для показа.

| Что | Зачем хранится |
|---|---|
| `слайды/` | исходники слайдов: `slides.html`, `slides.css` |
| `речь/` | исходники речи: `speech.html`, `speech.css` |
| `книга/` | исходники книжки: `book.html`, `book.css`, `src/*.puml`, `img/*.png` (300 dpi) |
| `diagrams/` | 42 файла диаграмм из репозитория — на A4 нечитаемы (шрифт 2–3 pt) |
| `ФМС — подготовка к защите.md` / `.pdf` | полная версия «на отлично»: контракты всех операций |
| `ФМС — шпаргалка на защиту.md` / `.pdf` | старая шпаргалка (заменена книжкой и речью) |
| `ФМС — план ознакомления.md` | план подготовки на день |

## Пересборка документов

Диаграммы (нужны только если правились `.puml`):

```bash
cd "5sem/Функциональное моделирование систем/_архив/книга"
plantuml -tpng -Sdpi=300 -o ../img src/*.puml
```

Документы — из папки каждого исходника:

```bash
cd _архив/слайды && uvx weasyprint slides.html "../../защита/ФМС — слайды.pdf"
cd _архив/речь   && uvx weasyprint speech.html "../../защита/ФМС — что говорить.pdf"
cd _архив/книга  && uvx weasyprint book.html   "../../защита/ФМС — книжка для подготовки.pdf"
cd _архив/книга  && uvx weasyprint report.html "../../защита/ФМС — отчёт.pdf"
```

Проверка: `pdfinfo "... | grep Pages` → слайды 22 (960×540 pt), речь 11, отчёт 16, книжка 18.

## Почему диаграммы перерисованы

Исходные диаграммы (`diagrams/`) рассчитаны на экран: при печати на A4 шрифт получается 2–3 pt,
линии сливаются. В книжке и на слайдах — упрощённые версии крупным шрифтом (20 pt, рендер 300 dpi),
в подписях указано, что полные диаграммы есть в репозитории `github.com/mflkee/fms-course`.
