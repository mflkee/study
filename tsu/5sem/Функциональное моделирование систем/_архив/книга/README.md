# Книжка ФМС — как пересобрать

Печатная версия для защиты на базовом уровне: 18 страниц A4, поля под сшивку,
колонтитулы и номера страниц у внешнего края.

## Файлы

| Файл | Что это |
|---|---|
| `book.html` | текст книжки (правится здесь) |
| `book.css` | вёрстка: A4, зеркальные поля, колонтитулы, номера страниц |
| `src/*.puml` | исходники упрощённых диаграмм (PlantUML) |
| `img/*.png` | готовые диаграммы в 300 dpi |
| `../../защита/ФМС — книжка для подготовки.pdf` | результат |

## Пересборка

```bash
cd "защита/книга"

# 1. диаграммы: PlantUML ставит подписи корректно только в PNG (в SVG ломает акторов)
plantuml -tpng -Sdpi=300 -o ../img src/*.puml

# 2. PDF
uvx weasyprint book.html "../../защита/ФМС — книжка для подготовки.pdf"
```

Проверка: `pdfinfo "../../защита/ФМС — книжка для подготовки.pdf" | grep Pages` → должно быть 18.

## Почему диаграммы перерисованы

Диаграммы из репозитория рассчитаны на экран: при печати на A4 их шрифт получается 2–3 pt,
линии сливаются. Поэтому для книжки сделаны упрощённые версии крупным шрифтом (20 pt,
рендер 300 dpi). В подписях указано, что полные диаграммы — в репозитории.

## Печать

- A4, двусторонняя, переплёт по длинному краю (duplex long-edge).
- Внутреннее поле 25 мм, внешнее 18 мм: при сшивке текст и колонтитулы не протыкаются.
- Номера страниц — внизу у внешнего края.
