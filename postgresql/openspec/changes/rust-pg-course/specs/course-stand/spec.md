# Spec Delta

## Purpose

Описывает стенд и верификацию курса: воспроизводимый Docker-стенд на зафиксированных версиях, автоматические проверки запускаемого кода и правила пометки непроверенного контента.

## ADDED Requirements

### Requirement: Воспроизводимый стенд

Инфраструктура курса SHALL быть организована единым файлом `infra/docker-compose.yml`, который поднимает нужные сервисы одной командой без ручной магии. Разные наборы сервисов для разных модулей SHALL разноситься по profiles compose. Образы и сервисы стенда SHALL соответствовать версиям, заявленным в плане курса (PostgreSQL 18.6; Prometheus/Grafana, TimescaleDB — по мере нужды соответствующих модулей).

#### Scenario: Стенд поднимается одной командой

- **WHEN** выполняется `docker compose up -d` в каталоге `infra/` (или с profile конкретного модуля)
- **THEN** все сервисы набора переходят в состояние healthy/running без ручных действий

#### Scenario: Compose-файл валиден

- **WHEN** выполняется `docker compose config`
- **THEN** команда завершается с кодом 0 и без ошибок конфигурации

### Requirement: Зафиксированные версии

Версии технологий курса SHALL быть зафиксированы в плане курса и соответствовать реально доступным и проверенным версиям на момент создания: PostgreSQL 18.6 (образ `postgres:18`), Rust 1.98, крейты sqlx 0.9, tokio 1.53, axum 0.8, rust_decimal 1.43, tokio-modbus 0.17.

#### Scenario: Версии соответствуют факту

- **WHEN** проверяется план курса
- **THEN** зафиксированные версии совпадают с фактическими версиями образов и крейтов, проверенными по официальным источникам

### Requirement: Проверка запускаемого кода

Каждый запускаемый артефакт курса SHALL быть проверен исполнением: Rust — `cargo check`, `cargo test`, `cargo clippy`; SQL — реальным запуском в PostgreSQL через Docker; compose-файлы — `docker compose config`. Артефакт, который проверить нельзя, SHALL быть помечен `<!-- UNVERIFIED -->` с объяснением причины.

#### Scenario: Rust-код проверен компиляцией и тестами

- **WHEN** выполняется `cargo test` в cargo-проекте модуля
- **THEN** команда проходит без ошибок, либо непроверенное явно помечено `<!-- UNVERIFIED -->`

#### Scenario: SQL проверен в реальном PostgreSQL

- **WHEN** выполняется SQL-скрипт курса против контейнера `postgres:18`
- **THEN** скрипт отрабатывает с ожидаемым результатом, либо помечен `<!-- UNVERIFIED -->`

### Requirement: Данные и миграции в репозитории

Миграции схемы и тестовые данные курса SHALL храниться в репозитории и применяться одной командой (без ручной настройки баз данных).

#### Scenario: Миграции применимы одной командой

- **WHEN** выполняется команда применения миграций из репозитория к свежему контейнеру PostgreSQL
- **THEN** схема создаётся полностью, без ручных шагов
