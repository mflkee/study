# Модуль 02: Проектирование схемы (schema-design)

**Цели модуля:**
- Понимать нормализацию (1NF–3NF), ключи и связи — и применять на справочниках оборудования.
- Выбирать тип индекса под запрос: B-tree, BRIN, GIN, partial — и читать `EXPLAIN`.
- Проектировать схему под временные ряды телеметрии (append-only, ключ запроса, ретеншн).

**Пререквизиты:** модуль 01 (SQL-фундамент), стенд PostgreSQL 18.6, применённые `00-schema-katalog.sql` + `01-seed-katalog.sql`.

**План (по `course/PLAN.md`, ~8 ч):**
1. Урок 01: нормализация, ключи, связи (~2 ч)
2. Урок 02: индексы — B-tree, BRIN, GIN, partial; EXPLAIN (~2.5 ч)
3. Урок 03: проектирование схемы под телеметрию (~1.5 ч)
4. Упражнения 01–02 с автопроверкой (~1 ч)
5. Лаба «BRIN vs B-tree под запросы телеметрии» (~1 ч)
