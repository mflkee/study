# Модуль 01: SQL-фундамент (sql-foundations)

**Цели модуля:**
- Свободно писать `SELECT`/`INSERT`/`UPDATE`/`DELETE` с фильтрами, сортировкой, JOIN и агрегатами.
- Понимать разницу `NUMERIC` vs `float8`, `timestamptz` vs `timestamp` — и выбирать типы под метрологию.
- Владеть подзапросами, CTE и оконными функциями на уровне сменных/суточных отчётов.
- Прокачать сквозные кейсы: «каталог оборудования», «точность расчётов», «сменные отчёты».
