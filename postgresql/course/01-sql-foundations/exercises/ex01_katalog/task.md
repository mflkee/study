# Упражнение 01: Каталог оборудования — наполни справочник

**Кейс:** 1 (каталог оборудования)
**Модуль:** 01-sql-foundations
**Время:** 30 мин
**Сложность:** реши сам

## Условие

ТЗ: на складе развернули новую линию. Добавь в справочник:

1. Линию `ЛИНИЯ-4` (описание: `линия измерения №4`).
2. На неё два устройства:
   - массомер `M-04-001` (модель `CMF-100`);
   - влагомер `W-04-001` (модель `MVM-3`).

Используй `INSERT ... RETURNING`, чтобы получить `id` линии для вставки устройств. Схема уже применена (`00-schema-katalog.sql` + `01-seed-katalog.sql`) и данные сида на месте.

Заготовка: `student.sql` (добавляет только линию — заполни устройства).

## Как проверить

```bash
infra/check-sql.sh course/01-sql-foundations/exercises/ex01_katalog/student.sql \
                   course/01-sql-foundations/exercises/ex01_katalog/asserts.sql
```

Выход 0 с сообщением `ok: проверка пройдена` — решение верное. Проверка выполняется в транзакции (ROLLBACK): справочник не засоряется.

## Критерии ассертов

- Линия `ЛИНИЯ-4` существует.
- На ней ровно 2 устройства.
- Теги `M-04-001` (mass_meter) и `W-04-001` (moisture_meter) присутствуют, ссылаются на `ЛИНИЯ-4`.

Решение — в `../../solutions/ex01_katalog.sql` (после своей попытки).
