# Упражнения модуля 05

## Заготовка и решение

- Заготовка: `exercises/src/ex01_pipeline.rs` — «Пайплайн опроса датчиков»: `produce` → bounded-канал → `consume`, всё три функции с `todo!()`, параметры с `_`-префиксом (намеренно: в заготовке не используются).
- Подключена в проект через `src/lib.rs` (`#[path = "../exercises/src/ex01_pipeline.rs"]`), поэтому компилируется и тестируется.
- Решение: `solutions/ex01_pipeline.rs` — открывать после своей попытки, скопировать содержимое в заготовку.
- Референс с грациозным остановом (Ctrl-C) — пример `examples/05-pipeline.rs`.

## Как проверять

```bash
cargo test ex01_        # тесты упражнения
cargo test              # всё
```

Поведение «до/после»:

- **До решения** — тесты падают с `not yet implemented` (это норма: так устроены todo!()-заготовки).
- **После решения** — все тесты зелёные (4 шт.): лимит производителя, ничего не теряется, backpressure при медленном потребителе, пустой пайплайн.

Примеры проверяются запуском (см. README модуля): базовые принципы, каналы, backpressure, грациозный останов.
