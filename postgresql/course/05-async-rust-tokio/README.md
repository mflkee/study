# Модуль 05: Асинхронность (async-rust-tokio)

**Цели модуля:**
- Понимать async/await, `Future` и кооперативную многозадачность — и почему БД-слой на Rust делают асинхронным.
- Уверенно использовать задачи `tokio::spawn`, каналы `mpsc` и `select!`.
- Реализовать отмену и **грациозный останов** воркеров (Ctrl-C, остановка производителя, дренаж очереди).
- Понять **backpressure** на bounded-каналах — почему очередь не может быть бесконечной.
- Прокачать сквозной кейс «телеметрия»: пайплайн «опрос датчиков → канал → обработчик».

**Пререквизиты:** модуль 04 (Rust + PostgreSQL), базовое знакомство с async (на уровне «видел async/await»). БД в этом модуле нет — «запись в БД» моделируется асинхронной задержкой (мост к реальной БД — модуль 06).

**Структура модуля:** самостоятельный cargo-проект (design D7): `src/lib.rs` с упражнением, `examples/` — запускаемые демо, `exercises/src/ex01_pipeline.rs` — заготовка упражнения, `solutions/` — решения.

**План (по `course/PLAN.md`, ~8 ч):**
1. Урок 01: async/await, `Future`, конкурентность на одном потоке, блокирующие операции (~2 ч)
2. Урок 02: задачи `tokio::spawn`, каналы `mpsc`, `select!`, backpressure (~2.5 ч)
3. Урок 03: отмена и грациозный останов (Ctrl-C, дренаж, `biased;`, `pin!`) (~2 ч)
4. Упражнение 01: «Пайплайн опроса датчиков» + `cargo test` (~1.5 ч)
5. Лаба 01: «Грациозный останов воркера» (~1 ч)
