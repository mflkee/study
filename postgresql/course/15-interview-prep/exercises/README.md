# Упражнения модуля 15

## «Собеседование вслух»

`exercises/interview.md` — 10 вопросов в 4 блоках (SQL, PostgreSQL, Rust+БД, проектирование) с правилами самопроверки:
- отвечай вслух → открывай `<details>` → ставь ✅/⚠️ → в чеклист «чего не хватило» для повтора через неделю.

Поведение «до/после» (как у тест-заготовок курса):
- **до тренировки** — «почти» больше половины (запиши, где потерялся);
- **после** — каждый блок закрыт без запинок.
