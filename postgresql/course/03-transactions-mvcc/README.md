# Модуль 03: Транзакции и MVCC (transactions-mvcc)

**Цели модуля:**
- Понимать ACID и уверенно управлять транзакциями и savepoints из psql (и в коде — модуль 06).
- Различать уровни изоляции (read committed, repeatable read) и поведение MVCC.
- Разбираться в блокировках: строковые/табличные, deadlock, VACUUM и bloat, advisory locks.
- Строить очередь задач на `SELECT ... FOR UPDATE SKIP LOCKED` (кейс 7; в Rust — модуль 10).

**Пререквизиты:** модули 01–02, стенд PostgreSQL 18.6.

**Важно про этот модуль:** демонстрации двухсессионные — потребуется ДВА терминала (второй можно открыть внутри контейнера: `docker compose exec postgres psql -U course -d course`). Автор проверил все сценарии реальными параллельными сессиями; выводы в уроках — фактические.

**План (по `course/PLAN.md`, ~8 ч):**
1. Урок 01: ACID, BEGIN/COMMIT/ROLLBACK, savepoints (~1.5 ч)
2. Урок 02: уровни изоляции и MVCC (~1.5 ч)
3. Урок 03: блокировки, deadlock, VACUUM, advisory locks (~2.5 ч)
4. Урок 04: очередь задач на SKIP LOCKED (~1.5 ч)

6. Лаба «Сломай и почини: deadlock и долгая транзакция» (~1.5 ч)
