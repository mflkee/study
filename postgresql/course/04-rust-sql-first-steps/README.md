# Модуль 04: Первый Rust + PostgreSQL (rust-sql-first-steps)

**Цели модуля:**
- Обоснованно выбрать стек доступа к PostgreSQL из Rust: `sqlx` против `tokio-postgres` против ORM (diesel/sea-orm).
- Подключиться из Rust к стенду курса: пул соединений, первые `SELECT`/`INSERT` с параметрами.
- Мапить типы PostgreSQL → Rust: `numeric` → `rust_decimal::Decimal`, `timestamptz` → `chrono::DateTime<Utc>`, NULL → `Option<T>`.
- Прокачать сквозные кейсы: **«Каталог оборудования на Rust»** (кейс 1) и **«Масса нетто на rust_decimal»** (кейс 3, точность расчётов).
- Сериализовать телеметрию в JSON (`serde`) — задел REST-модуля 11.

**Пререквизиты:** модули 00–03 (стенд PostgreSQL 18.6 поднят), Rust на уровне базы (владение, трейты, ошибки, базовое async), SQL — на уровне модуля 01. Python/Docker не требуются.

**Структура модуля:** это самостоятельный cargo-проект (design D7): свой `Cargo.toml`, код в `src/`, запускаемые примеры в `examples/`, упражнения-заготовки в `exercises/src/`, решения — в `solutions/` (открывай после попытки).

**Работа со схемой:** каталог оборудования (`equipment_lines`, `devices`, `measurements`) — тот же, что в модулях 01–02. Если ты шёл по порядку — схема уже в БД. Если нет — примени самодостаточный скрипт один раз:

```bash
infra/apply-db.sh course/04-rust-sql-first-steps/examples/00-setup.sql
```

Скрипт идемпотентный: повторное применение безопасно (перезасеет сид).

**План (по `course/PLAN.md`, ~12 ч):**
1. Урок 01: выбор крейта доступа — tokio-postgres / sqlx / ORM (~2 ч)
2. Урок 02: подключение, первые запросы, маппинг типов (~2 ч)
3. Урок 03: rust_decimal, chrono, serde; батчевая запись (~2.5 ч)
4. Упражнение 01: «Каталог оборудования: SQL-слой на sqlx» (~2 ч)
5. Упражнение 02: «Масса нетто на rust_decimal» (~1.5 ч)
6. Лаба 01: «Считать из PG → посчитать → записать обратно» (~2 ч)
