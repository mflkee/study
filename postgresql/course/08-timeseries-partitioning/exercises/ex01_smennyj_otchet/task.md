# Упражнение 01: Отчёты за смену по каждой «линии»

**Кейс:** 5 (сменные и суточные отчёты)
**Модуль:** 08-timeseries-partitioning
**Время:** 30 мин
**Сложность:** реши сам

## Условие

На партиционированной таблице `measurements_part` (course_m06, 1 М строк, 8 устройств) нужен **сменный отчёт за сентябрь**: для каждого «устройства» (в учебных данных это device_id 1–8, аналог линий) — смены по 12 часов (бакеты от 2026-08-01 00:00) с агрегатами:

- `shift` — начало смены (12-часовой бакет);
- `device_id`;
- `n` — количество показаний;
- `total` — сумма значений (numeric, округлить до 2 знаков).

Используй `date_bin('12 hours', ts, '2026-08-01 00:00:00+00'::timestamptz)` (урок 02) и `GROUP BY`. Результат положи в **временную таблицу** `report_shifts` (её читают ассерты).

Заготовка: `student.sql` — заполни запрос.

## Как проверить

```bash
infra/check-sql.sh course/08-timeseries-partitioning/exercises/ex01_smennyj_otchet/student.sql \
                   course/08-timeseries-partitioning/exercises/ex01_smennyj_otchet/asserts.sql
```

Выход 0 с `ok: проверка пройдена` — решение верное (проверка в транзакции, данные не трогаются).

## Критерии ассертов

- `report_shifts` непустой (за сентябрь должно быть ~60 смен × 8 устройств).
- Суммы в отчёте совпадают с прямым запросом по тем же бакетам.
- Бакеты ровно 12-часовые (проверка «шага»).
