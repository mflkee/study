# Модуль 09: PL/pgSQL, триггеры, аудит, LISTEN/NOTIFY (plpgsql-triggers-notify)

**Цели модуля:**
- Писать функции PL/pgSQL: валидация, ошибки, триггеры.
- Строить журнал аудита с защитой от подмены: снимки строк, запрет правки, цепочка хэшей, проверка из Rust (кейс 4).
- Реагировать на изменения в реальном времени: триггер → NOTIFY → Rust-слушатель → таблица событий + квитирование (кейс 6).
- Разделять роли и применять RLS для строковых политик (урок 04).

**Пререквизиты:** модули 04–08 (sqlx, транзакции, производительность). Собственный cargo-проект; схема — в `course_m06`.

**Подготовка (один раз):**

```bash
cd infra && docker compose exec -T postgres psql -U course -d course_m06 -v ON_ERROR_STOP=1 -f - < ../course/09-plpgsql-triggers-notify/examples/00-setup.sql
```
