# Упражнение 01: Диагностика окружения

**Модуль:** 00-orientation
**Время:** 30 мин
**Сложность:** повтори за примером

## Условие

Напиши bash-скрипт `check_env.sh`, который проверяет, что окружение готово к курсу:

1. Установлены: `rustc`, `cargo`, `sqlx`, `docker` (утилита + плагин `docker compose`).
2. Стенд PostgreSQL поднят и отвечает: `docker compose exec postgres psql -U course -d course -c "SELECT 1;"` выполняется без ошибок.
3. Скрипт печатает найденные версии (например `rust: 1.98.1`).
4. Скрипт возвращает код 0, если всё на месте; ненулевой код — если чего-то не хватает или стенд не отвечает.

Заготовка: `check_env.sh` (каркас с секциями `# TODO`). Достаточно реализовать секции TODO и не сломать остальное.

## Как проверить

```bash
cd course/00-orientation/exercises
bash check_env.sh        # должен вернуть 0 и напечатать версии
```

Если хотя бы одна проверка не пройдена — скрипт должен завершиться с ненулевым кодом.

## Критерии

- `bash check_env.sh` возвращает 0 на рабочем окружении автора (все инструменты и стенд на месте).
- Каждая отсутствующая проверка «валит» скрипт (возврат ≠ 0).
- Решение не должно использовать внешние утилиты, кроме уже перечисленных.

Решение — в `solution ../solutions/ex01/check_env.sh` (открывай после своей попытки).
