# Модуль 00: Ориентация и окружение

**Цели модуля:**
- Понять, как устроен курс, и оценить свой стартовый уровень.
- Настроить окружение: Rust toolchain, Docker, клиент psql, sqlx-cli.
- Поднять стенд и выполнить первый запрос к PostgreSQL 18.6.

**Пререквизиты:** Docker (или Podman с поддержкой compose), доступ в сеть, ~10 ГБ свободного диска. Умение работать в терминале.

**План:**
1. `theory.md` — карта курса, окружение, стенд (конспект).
2. Урок 01: настройка окружения (Rust, Docker, psql, sqlx-cli) — ~40 мин.
3. Урок 02: подъём стенда и первый запрос к PostgreSQL — ~45 мин.
4. Урок 03: карта компетенций и самооценка — ~30 мин.
5. Упражнение «Диагностика окружения» — ~30 мин.
6. Лаба «Стенд поднят и отвечает» — ~1.5 ч.

**Оценка времени:** ~4 часа.

**Чеклист готовности (критерии «модуль пройден»):**
- [ ] `rustc --version`, `cargo --version`, `docker --version` выполняются без ошибок
- [ ] `sqlx --version` показывает 0.9.x
- [ ] `cd infra && docker compose up -d` поднимает PostgreSQL без ошибок
- [ ] `docker compose exec postgres psql -U course -d course -c "SELECT version();"` возвращает PostgreSQL 18.x
- [ ] Смоук-запрос `SELECT * FROM public.smoke;` возвращает строку «stand is up»
- [ ] Упражнение «Диагностика окружения» проходит автопроверку
- [ ] Лаба «Стенд поднят и отвечает» выполнена по критериям успеха
- [ ] Самооценка заполнена (урок 03), PROGRESS.md обновлён

**Следующий модуль:** `01-sql-foundations` — язык SQL (можно начинать, когда стенд поднят).
