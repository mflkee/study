# Модуль 12: Тестирование (testing)

**Цели модуля:**
- Интеграционные тесты с настоящим PostgreSQL в контейнерах (testcontainers) — изоляция и воспроизводимость.
- Фикстуры, тесты SQL-функций, тест миграций на свежей БД.
- Property-based тесты (proptest): инварианты массы нетто, накопление ошибки f64 (кейс 3).

**Пререквизиты:** модули 04–08 (масса нетто, миграции, decimal), Docker. Собственный cargo-проект; интеграционные тесты НЕ зависят от стенда курса (контейнеры изолированы).

**План (по `course/PLAN.md`, ~8 ч):**
1. Урок 01: testcontainers (~2 ч)
2. Урок 02: фикстуры и SQL-функции / sqlx::test (~2 ч)
3. Урок 03: property-based (proptest) (~2 ч)
4. Упражнение 01: property-функции массы (~1.5 ч)
5. Упражнение 02: фикстуры и вызов функции (~1.5 ч)
6. Лаба 01: тест миграций на свежей БД (~1 ч)

**Чеклист готовности:**
- [ ] `cargo test --test pg_integration` зелёный (нужен Docker; контейнер на тест)
- [ ] `cargo test --test property` зелёный (инварианты массы нетто)
- [ ] Упражнения 01–02: заготовки → решения, тесты зелёные
- [ ] Лаба: тест миграций расширен (история, таблицы, функция, индекс); сломал миграцию — тест упал
- [ ] `cargo clippy`/`fmt` без замечаний; `PROGRESS.md` обновлён
