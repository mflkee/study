# Теория модуля 12: тестирование

Конспект-справочник. Развёрнутые примеры — в уроках (`lessons/`).

## Интеграционные тесты с testcontainers (урок 01)

- `testcontainers-modules::postgres::Postgres` (фича `postgres`); `start().await` → порт `get_host_port_ipv4`; URL собирается руками; контейнер чистится при drop.
- Тесты в `tests/`; каждый тест — свой контейнер (изоляция, параллельность, случайные порты).
- Это фундамент CI: тесты против настоящей БД без общего стенда.

## Фикстуры и SQL-функции (урок 02)

- Фикстуры — детерминированные данные в тесте (`insert_fixtures`); SQL-функция вызывается (`SELECT order_total($1)`) и сверяется.
- Negative-кейсы (нет заказа) — часть теста; `numeric` → `Decimal`, не строка.
- `sqlx::test` — альтернатива с авто-созданными БД и откатом на тест (упомянут; в курсе изоляцию дают testcontainers).

## Property-based (урок 03)

- `proptest! { #[test] fn p(in range) { assert!(инвариант) } }` — тысячи входов, shrinking при провале; стиль единый (`assert!`+`()` или `prop_assert!`+`Result`).
- Инварианты массы нетто: `0 ≤ нетто ≤ брутто`, конечность, валидация; `diff_on` — расхождение f64 vs decimal на «десятых» (накопление ошибки).
- Сломай функцию на минуту — property-тест обязан упасть (реальность инвариантов).
