# Курс «Rust + PostgreSQL для СИКН»

Практический курс для самостоятельного обучения: Rust-приложения поверх PostgreSQL — от SQL и проектирования схем до асинхронного доступа, миграций, тестов, производительности и эксплуатации. Вся практика строится вокруг предметной области ученика: системы измерения количества и качества нефти (СИКН), Modbus-телеметрия, SCADA, метрологическая точность и аудит.

## Как устроен курс

- **16 модулей** (`00-orientation` … `15-interview-prep`). Проходить строго по порядку: каждый модуль опирается на предыдущие.
- Единая структура модуля: `README.md` (цели и чеклист), `theory.md` (конспект), `lessons/` (пошаговые уроки), `examples/` (рабочие примеры), `exercises/` (задания с автопроверкой, решения в `solutions/`), `labs/` (лабы «сломай и почини» и мини-проекты).
- Rust-модули — самостоятельные cargo-проекты (`Cargo.toml`, `examples/`, `exercises/src/` с `lib.rs` и тестами).
- Соотношение **30% чтения / 70% практики**: каждый урок заканчивается заданием, которое нужно написать самому.
- Стенд: единый `docker-compose.yml` в `infra/` (PostgreSQL 18.6 + опциональные профили). Одной командой поднимается всё нужное.

## Как начать

1. Прочитай `00-orientation/README.md`.
2. Подними стенд: `cd infra && docker compose up -d` (нужен Docker).
3. Пройди модуль 00: проверь окружение, сделай первый запрос к PostgreSQL.
4. Дальше — по порядку, отмечая прогресс в `PROGRESS.md`.

Ссылки на официальную документацию — в `resources/README.md`.
