# Модуль 10: Паттерны приложений (app-patterns)

**Цели модуля:**
- Repository-паттерн и правильные границы транзакций из Rust.
- Outbox: атомарные «данные + событие», идемпотентность доставки.
- Очередь задач на PostgreSQL: воркеры tokio, `SKIP LOCKED`, ретраи с бэкoff, dead-letter (кейс 7).
- Буферизация при потере связи: локальный буфер шлюза → доставка без дублей (кейс 8).
- Миграции без даунтайма и обратная совместимость (кейс 10).

**Пререквизиты:** модули 03–09 (SKIP LOCKED, транзакции, NOTIFY, очередь-каналы). Собственный cargo-проект; схема — в `course_m06`.

**Подготовка (один раз):**

```bash
cd infra && docker compose exec -T postgres psql -U course -d course_m06 -v ON_ERROR_STOP=1 -f - < ../course/10-app-patterns/examples/00-setup.sql
```
