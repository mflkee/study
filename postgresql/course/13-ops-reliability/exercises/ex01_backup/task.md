# Упражнение 01: Стратегия бэкапа скриптами + проверка восстановления

**Кейс:** 12 (инциденты — RPO/RTO)
**Модуль:** 13-ops-reliability
**Время:** 45 мин
**Сложность:** реши сам

## Условие

Напиши свой скрипт бэкапа `backup.sh` (по образцу `examples/01-pgdump-restore.sh`, но по-своему):

- логический дамп `course_m06` (custom-формат) в папку `backups/`;
- имя файла с датой (`course_m06_YYYYmmdd_HHMMSS.dump`);
- ротация: оставить только последние 7 файлов;
- **проверка восстановления**: restore дампа в пробную базу `course_m06_restore` и сверка `count(*)` по `alarms` (источник vs restore) — при расхождении скрипт падает (exit ≠ 0).

Заготовка: `student.sh` — скелет с `TODO` (заполни). Проверка: `infra/check-backup.sh`? Нет — автопроверка собственная:

```bash
bash course/13-ops-reliability/exercises/ex01_backup/student.sh
```

и она сама выводит сверку. Успех: exit 0, рассказанная вслух схема «что сколько стоит по времени/RPO».

## Критерии

- Файл дампа появился в `backups/` с датой
- Ротация: после 3 запусков ≤ 7 файлов (проверка списком)
- Restore в `course_m06_restore`: `count(*)` совпал
- Сформулировал RPO/RTO для своей стратегии (в notes)

Решение — в `../../solutions/ex01_backup.sh`.
