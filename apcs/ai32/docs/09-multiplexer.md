# Глава 9. Подключение каналов: три АЦП вместо мультиплексора

> [Вернуться к карте глав](README.md)

## Зачем три чипа

У модуля 24 аналоговых входа. Раньше в эскизе был один 16-битный АЦП на всех —
и 32 канала коммутировали деревом мультиплексоров CD4051B (32:1). Это дёшево,
но даст **один АЦП на все каналы**: разрешение ограничено 16 битами, а выборка
идёт через длинную цепочку ключей.

Новая схема (по требованию к 24-битной точности): входы делятся на **три группы
по 8 каналов**, каждую группу обслуживает свой 24-битный АЦП **ADS1256**.
Мультиплексоров нет вообще.

- **3 × 8 = 24 канала** — на каждый вход приходится полноразрядный
  24-битный канал;
- все три чипа висят на **одной SPI-шине** (общие SCLK/MOSI/MISO);
- выбор кристалла — **тремя GPIO** (CS0, CS1, CS2), по одному на чип;
- огромный плюс: шум «соседних» каналов не попадает в измеряемый канал, как в
  общем тракте с мультиплексором.

```
            ┌────────────┐   ┌────────────┐   ┌────────────┐
   входы ──▶│ ADS1256 #0 │   │ ADS1256 #1 │   │ ADS1256 #2 │
   0..7 ───▶│  каналы    │   │  каналы    │   │  каналы    │
   8..15 ──▶│  0..7      │──▶│  8..15     │──▶│  16..23    │
   16..23 ─▶│            │   │            │   │            │
            └────────────┘   └────────────┘   └────────────┘
               CS0=GPIO10       CS1=GPIO9        CS2=GPIO8
                      └──────────┴────────┴────────┘
                              общая SPI (SCLK/MOSI/MISO)
                                     │
                                   ESP32-S3
```

## Как разложить канал 0..23 на «чип + вход»

Используем простейшее деление на 8:

```
chip  = channel / 8      // 0..2 → какой CS дергать
input = channel % 8      // 0..7 → какой вход внутри чипа
```

Примеры:

| Канал | chip | input | CS      | Вход чипа |
|-------|------|-------|---------|-----------|
| 0     | 0    | 0     | GPIO10  | AIN0      |
| 7     | 0    | 7     | GPIO10  | AIN7      |
| 8     | 1    | 0     | GPIO9   | AIN0      |
| 19    | 2    | 3     | GPIO8   | AIN3      |
| 23    | 2    | 7     | GPIO8   | AIN7      |

## Почему не конфликтуют шины

В один момент времени «говорим» только с одним чипом: подняли остальные CS в
высокий уровень (выключены), опустили нужный — и общая шина принадлежит только
ему. Это тот же принцип, что был у невыбранных мультиплексоров
(high-impedance), только проще: выбирается не «адресом», а одной ногой CS.

## Выбор кристалла — три GPIO, а не мультиплексор логики

Каждая CS-нога — отдельный GPIO ESP32 (GPIO10/9/8), активный низкий.
Никаких сдвиговых регистров и 74HC595 не нужно: «адрес» чипа — это просто три
отдельных провода через барьер.

## Что с 16-битным усилительным опцией

Усиление на входе не требуется: даже без Ku>1 полезный сигнал 0,66–3,3 В
занимает ~52 % шкалы 24-битного АЦП (см. [главу 7](07-adc-scaling.md)).
Буфер OPA320 на входе остаётся только как согласование импедансов
([глава 6](06-opa320.md)), а не как усилитель.

## Связано с кодом

Формула `chip = channel / 8`, `input = channel % 8` живёт в
`Ads1256::read_channel` — `fw/src/ads1256.rs`:

```rust
let chip = (channel / 8) as usize;   // выбор CS0..CS2
let local_channel = channel % 8;     // вход внутри чипа
```

Аппаратный CS в `esp-idf-hal` при этом не используется (`spics_io_num = -1` в
`SpiBusDriver`): выбор кристалла делается тремя GPIO вручную — ровно как в
схеме этой главы.

Номер канала един во всех слоях проекта: индекс входной группы, индекс в
`ChannelBank`, адрес в Modbus (`core/src/channels.rs`,
`core/src/register_map.rs`).
