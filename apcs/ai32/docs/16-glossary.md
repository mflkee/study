# Глава 16. Глоссарий

> [Вернуться к карте глав](README.md)

| Термин | Что это простыми словами |
|---|---|
| **Шунт** | Точно подобранный резистор малого сопротивления, превращающий ток в напряжение по закону Ома. В модуле — 165 Ом ([глава 3](03-shunt.md)). |
| **TVS-диод (транзил)** | «Предохранитель» по напряжению: пока напряжение в норме, он ничего не делает; при скачке «зажимает» его до безопасного уровня и пропускает энергию мимо схемы ([глава 4](04-input-protection.md)). |
| **PTC** | Самовосстанавливающийся предохранитель: при перегрузке по току его сопротивление резко растёт, ток падает; после устранения аварии «отпускает» сам ([глава 4](04-input-protection.md)). |
| **Мультиплексор** | Электронный переключатель, который по адресному коду подключает на один общий выход один из множества входов. В текущей схеме **не используется**: 24 канала делятся на три АЦП по 8, выбор кристалла — тремя GPIO (CS0..CS2) ([глава 9](09-multiplexer.md)). |
| **HOLDING / INPUT / COIL** | Типы регистров Modbus. HOLDING-регистры — 16-битные, доступны и на чтение, и на запись. INPUT-регистры — 16-битные, только чтение (источники измерений). COIL — однобитовая «лампа» на запись/чтение (например, сигнальные флаги). |
| **NVS** | Энергонезависимая память (non-volatile storage) внутри ESP32: данные не пропадают при выключении питания. Туда пишут коэффициенты калибровки ([глава 13](13-pcb-calibration.md), `fw/src/config_store.rs`). |
| **ppm** | Parts per million — «миллионная доля». 1 ppm = 0,0001 %. Используется для обозначения малых допусков и температурных коэффициентов ([глава 3](03-shunt.md)). |
| **LSB** | Least significant bit — младший (минимальный) разряд цифрового значения. Цена LSB = диапазон / количество кодов ([глава 7](07-adc-scaling.md)). |
| **Опорное напряжение** | «Эталон», с которым АЦП сравнивает сигнал: напряжение, соответствующее верхней границе диапазона. Если оно «плавает», плавают и все измерения ([глава 14](14-critical-notes.md), п. 7). |
| **ADuM / ISOxxxx** | Семейства цифровых изоляторов: микросхемы, передающие данные через магнитный барьер без электрического контакта между доменами ([глава 8](08-isolation.md)). |
| **DC-DC** | Преобразователь напряжения «постоянное в постоянное»: из 24 В делает 5 В, изолированный (B0505S) — ещё и с гальванической развязкой ([главы 11–12](11-power.md)). |
| **Buck (buck-преобразователь)** | Понижающий DC-DC: выдает напряжение ниже входного. «24 В → 5 В» — типичный buck ([главы 11–12](11-power.md)). |
| **LDO** | Линейный стабилизатор: из чуть большего напряжения делает стабильное меньшее, но лишнее «сжигает» в тепло. «Из 5 В делает чистые 3,3 В» ([глава 11](11-power.md)). |
| **SPI** | Тактовый последовательный интерфейс с линиями SCLK/MOSI/MISO/CS — так ESP32 общается с тремя АЦП ADS1256 на общей шине ([глава 10](10-ads8681-spi.md)). |
| **Термо-ЭДС** | Микро-напряжение, возникающее на границе двух разных металлов при разной температуре. Из-за высокой цели по точности его приходится учитывать при разводке платы ([глава 13](13-pcb-calibration.md)). |
| **ИВК** | Информационно-вычислительный комплекс — по-простому, «главный промышленный компьютер», собирающий данные с множества устройств по сети ([глава 1](01-overview.md)). |
| **Идеальный диод (на P-MOSFET)** | Схема, которая ведёт себя как диод, но с почти нулевым падением напряжения и без нагрева — защита от перепутывания полярности ([глава 12](12-power-protection.md)). |
| **RS-485** | Промышленный последовательный интерфейс по витой паре (дифференциальный сигнал, помехоустойчивый, много устройств на одной шине). Модуль отдаёт данные в ИВК именно по RS-485 + Modbus RTU ([глава 1](01-overview.md)). |
| **PDU** | Protocol Data Unit — «полезная нагрузка» кадра: `[fc][data...]` без транспортной обвязки ([глава 15](15-firmware.md)). |
