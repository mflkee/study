# Глава 10. SPI-интерфейс ADS1256 (3 чипа на общей шине)

> [Вернуться к карте глав](README.md)

АЦП подключаются к ESP32 через интерфейс **SPI**.

## Что такое SPI (кратко)

SPI — четырёхпроводной синхронный последовательный интерфейс: есть тактовый
сигнал (SCLK), две линии данных (одна от мастера — MOSI, одна к мастеру —
MISO) и сигнал выбора чипа (CS). «Мастер» (ESP32) задаёт такты и решает, когда
опрашивать устройство.

## Общая шина и выбор кристалла

Три ADS1256 висят на **одной** SPI-шине: SCLK/MOSI/MISO общие, а у каждого чипа
своя нога **CS**. Выбор кристалла — это просто опустить нужную CS (активный
низкий) и разговаривать; остальные CS подняты, их чипы молчат.

```
SCLK = GPIO12   (такты SPI, общие для всех трёх чипов)
MOSI = GPIO11   (команды от ESP32 к АЦП: WREG/RDATA)
MISO = GPIO13   (24-битные отсчёты от АЦП к ESP32)
CS0  = GPIO10   (чип #0, каналы 0..7)
CS1  = GPIO9    (чип #1, каналы 8..15)
CS2  = GPIO8    (чип #2, каналы 16..23)
DRDY = GPIO14   (необязательно: сигнал готовности данных)
```

> ⚠️ Примечание: номеров GPIO достаточно для логики проекта, но **точную распайку
> конкретной платы HW-678 нужно проверить по её шелкографии** (маркировке на
> плате). Используются линии второго аппаратного SPI-модуля (SPI2/HSPI).
> Полностью — в [`PINMAP.md`](PINMAP.md).
> DRDY/SYNC/RESET каждого ADS1256 в каркасе опущены (TODO) — обычно их
> объединяют и вешают на один GPIO.

## Режим SPI и скорость

Для ADS1256 используется **SPI Mode 1** (CPOL = 0, CPHA = 1). Что это значит:
такты начинаются с низкого уровня, а данные читаются по заднему фронту.
Перед финальной проверкой работы обязательно **сверить этот режим с актуальной
редакцией даташита ADS1256** — TI иногда меняет рекомендации между версиями
документации.

Скорость шины в каркасе — **1 МГц**. Для дельта-сигма АЦП это более чем
достаточно: даже при типовом DRATE в десятки кSPS у чипа много времени между
выборками, а протокол короткий (команда + 3 байта данных).

## Протокол чтения ADS1256 (кратко)

ADS1256 — командно-регистровый АЦП:

1. **WREG MUX** (запись регистра MUX, адрес 0x01) — выбрать вход внутри чипа;
   канал кодируется в старшие биты, «земля» измерения — AINCOM;
2. **подождать время установления** (у дельта-сигма АЦП смена входа требует
   лишней выборки, чтобы цифровой фильтр перестроился);
3. **RDATA** (0x01) — по этой команде чип выдаёт **24 бита** результата,
   старшим байтом вперёд.

Детали команд и регистров — в datasheet ADS1256 («Command Definitions»,
«Register Description»). В `fw/src/ads1256.rs` места, требующие сверки,
помечены `TODO`.

## Почему CS на GPIO, а не аппаратно

У `esp-idf-hal` `SpiBusDriver` создаётся с `spics_io_num = -1` — аппаратный CS
ESP32 не используется вообще. Выбор кристалла делается тремя GPIO вручную:
это даёт ту самую схему «общая шина + 3 CS» из [главы 9](09-multiplexer.md)
и не требует держать в ESP32 три отдельных SPI-контроллера.
