# AI-32 — документация модуля (иерархия глав)

> 24-канальный модуль аналогового ввода **4–20 мА** на базе **ESP32-S3**
> (плата HW-678) + **3× ADS1256** (24 бита) + **OPA320**, с выдачей в ИВК
> по **Modbus RTU via RS-485**.

Это **путеводитель** по технике модуля и его прошивке. Всё разбито на главы
так, чтобы каждая отвечала на один вопрос: «что на плате», «почему так
сделано», «где это в коде».

## Как читать (маршруты)

Выберите свой маршрут.

### 🧮 «Инженер аналоговой схемы» — понять плату
```
01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11 → 12 → 13 → 14
```

### 💻 «Программист прошивки» — понять, где что
```
01 → 02 → 07 → 09 → 10 → 15 → [код core/ и fw/]
```
Глава 15 — мост между «схемой» и «Rust»: в ней каждая позиция платы
сопоставлена с модулем прошивки.

### 🧑‍🏫 «Учусь» — в порядке курса (модуль 09 в `../course/09-ai32-module/`)
```
01 → 02 → 03 → 07 → 09 → 10 → 13 → 15 → [лабораторные в course/09]
```

## Связь «глава ↔ код»

Каждая глава внизу содержит блок **«Связано с кодом»** — какой файл core/fw
реализует именно эту часть и что там искать:

| Железо из глав | Код | Файл |
|----------------|-----|------|
| Шунт, LSB, калибровка (03, 07, 13) | `Calibration`, `from_points` | `core/src/calib.rs` |
| 24 канала, флаг включения (09) | `ChannelBank` | `core/src/channels.rs` |
| Карта регистров Modbus (15) | `dispatch`, FC01..FC06 | `core/src/register_map.rs` |
| CRC RTU (15) | `crc16/verify_crc` | `core/src/crc.rs` |
| 3× АЦП, выбор кристалла CS (09, 10) | `Ads1256` | `fw/src/ads1256.rs` |
| RTU-сервер по RS-485 (15) | `rtu_slave::spawn` | `fw/src/rtu_slave.rs` |
| NVS для калибровки (13) | `CalibStore` | `fw/src/config_store.rs` |

## Сборка и проверка кода

```text
# чистая логика (без железа) — на любом ПК:
cd ../core && cargo test          # 16 тестов: калибровка, каналы, Modbus, CRC

# прошивка — два режима:
cd ../fw
cargo +esp check                        # sim: АЦП имитируется (по умолчанию)
cargo +esp check --no-default-features  # real: 3×ADS1256 + SPI
```

Про структуру репозитория и порядок изучения — см. [`../README.md`](../README.md).
