# PINMAP — распиновка модуля AI-32 (ESP32-S3, плата HW-678)

> ⚠️ **Перед пайкой/прошивкой сверьте распайку с маркировкой конкретной платы
> HW-678** — у разных ревизий шелкография выводов может отличаться. Линии
> указаны для второго аппаратного SPI-модуля (SPI2/HSPI).

## SPI2/HSPI — общая шина трёх АЦП ADS1256

Все три кристалла висят на **одной** SPI-шине (общие SCLK/MOSI/MISO), выбор
кристалла — отдельными ногами CS0..CS2. Мультиплексоров нет.

| Сигнал    | ESP32-S3 | Назначение                          |
|-----------|----------|-------------------------------------|
| SCLK      | GPIO12   | такты SPI (Mode 1: CPOL=0, CPHA=1)  |
| MOSI/SDI  | GPIO11   | команды от ESP32 к АЦП (WREG/RDATA) |
| MISO/SDO  | GPIO13   | 24-битные отсчёты от АЦП к ESP32    |
| CS0       | GPIO10   | выбор чипа #0 (каналы 0..7), активный низкий  |
| CS1       | GPIO9    | выбор чипа #1 (каналы 8..15), активный низкий |
| CS2       | GPIO8    | выбор чипа #2 (каналы 16..23), активный низкий|
| DRDY0     | GPIO14   | необязательно: готовность данных чипа (сигнал тревоги/опрос) |

> DRDY/SYNC/RESET от ADS1256 в каркасе опущены (см. `fw/src/ads1256.rs`,
> раздел TODO) — обычно объединяют все чипы и вешают на один GPIO.

## Мультиплексоров нет — есть выбор кристалла GPIO

Каждый ADS1256 — по 8 входов; адрес канала `0..23` раскладывается так:

| Канал (0..23) | Чип (CS)       | Вход внутри чипа |
|---------------|----------------|------------------|
| 0..7          | #0 (GPIO10)    | 0..7             |
| 8..15         | #1 (GPIO9)     | 0..7             |
| 16..23        | #2 (GPIO8)     | 0..7             |

Формула: `chip = channel / 8`, `input = channel % 8` (реализация — в
`fw/src/ads1256.rs::read_channel`).

## Последовательный интерфейс (Modbus RTU via RS-485)

| Сигнал       | ESP32-S3 | Назначение                        |
|--------------|----------|-----------------------------------|
| UART0 TXD    | GPIO43   | TX → вход DI трансивера (MAX3485) |
| UART0 RXD    | GPIO44   | RX ← выход RO трансивера          |
| DE/RE        | GPIO7    | управление направлением RS-485 (TODO в fw) |
| USB-DM / USB-DP | GPIO19 / GPIO20 | USB-порт отладки платы HW-678 |

> Для стенда RTU можно использовать USB-UART напрямую; по RS-485 линия —
> дифференциальная пара A/B через трансивер MAX3485/MAX485.

## Питание

| Вывод        | Назначение                         |
|--------------|------------------------------------|
| 3V3 юбки     | питание цифры (ESP32, АЦП)         |
| 5V           | питание аналоговой части/буферов; AVDD ADS1256 (через LC-фильтр) |
| GND          | общий (все земли аналога и цифры)   |

> Аналоговые земли датчиков 4–20 мА подключаются к **одной** точке земли
> (звезда), а не «цепочкой» по входам.
