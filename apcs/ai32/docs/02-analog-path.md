# Глава 2. Аналоговый тракт одного канала

> [Вернуться к карте глав](README.md)

Разберём, что происходит с сигналом от клеммы модуля до цифрового числа.
Это важно понять, потому что каждая ступень сделана не «от балды», а для
конкретной инженерной цели.

```
IN+ ──→ [24,9 Ом] ──┬── [шунт 165 Ом] ──┐   (к IN- / AGND)
                    │                   │
                   [TVS3300]           [1 кОм] ── [100 нФ] ── AGND
                    │                   │
                    │                   └──→ на вход АЦП (ADS1256)
IN- ──→ [24,9 Ом] ──┴───────────────────┘   (IN- через шунт идёт на AGND)
```

По шагам:

1. **Ток 4–20 мА заходит на клемму IN+.** Внутри он проходит через защитные
   элементы (резисторы 24,9 Ом, TVS-диод, плавкий предохранитель PTC —
   см. [главу 4](04-input-protection.md)) — они вносят небольшое, но важное для
   расчёта падение напряжения.
2. **Ток протекает через шунт 165 Ом** (прецизионный резистор). По закону Ома
   напряжение на шунте:
   - при 4 мА: `U = 0,004 × 165 = 0,660 В`;
   - при 20 мА: `U = 0,020 × 165 = 3,300 В`;
   - размах (спан) сигнала: **2,640 В**.
3. **Напряжение фильтруется** RC-цепочкой (1 кОм + 100 нФ), чтобы отсечь
   высокочастотные помехи — см. [главу 5](05-rc-filter.md).
4. **Фильтрованный сигнал попадает на вход АЦП ADS1256**
   ([глава 9](09-multiplexer.md)). Мультиплексора нет: каждый чип обслуживает
   свои 8 входов напрямую, а 24 канала делятся на три кристалла.
5. **Согласование с АЦП делает буфер OPA320** ([глава 6](06-opa320.md)) — чтобы
   АЦП «видел» источник с низким выходным сопротивлением и не «съедал» заряд
   с фильтра.
6. **АЦП ADS1256 превращает напряжение в число** ([глава 7](07-adc-scaling.md)):
   24-битный дельта-сигма преобразователь, чем больше напряжение, тем больше
   код.

Полная цепочка «от клеммы до байтов ESP32»:

```
24 входа → (3× ADS1256 по 8 каналов, 24 бита, CS0..CS2) → общая SPI → ESP32-S3
                                        │
                            OPA320 (Ku=1, VDD=5 В) на каждую входную линию
```

Каждый элемент этой цепочки подробно разобран дальше — от главы 3 до главы 10.

## Связано с кодом

Код «видит» только последние два шага: за OPA320 стоит АЦП (реальный в
[главе 10](10-ads8681-spi.md)), а напряжение на АЦП превращается в ток уже в
чистом ядре:

| Ступень тракта | Код |
|----------------|-----|
| 3× ADS1256 + обход по SPI (выбор кристалла CS) | `Ads1256` — `fw/src/ads1256.rs` |
| Физический закон «напряжение → код АЦП» | `ADC_LSB_V` — `core/src/calib.rs` |
| «Код → миллиамперы» (калибровка) | `Calibration::current_ma` — `core/src/calib.rs` |
