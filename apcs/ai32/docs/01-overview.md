# Глава 1. Что за модуль и зачем

> [Вернуться к карте глав](README.md)

Модуль AI-32 — готовый узел, который подключается к **ИВК** (информационно-вычислительному
комплексу, по-простому — промышленному компьютеру, собирающему данные с датчиков).
Модуль умеет **одновременно читать 24 аналоговых сигнала**, каждый из которых
приходит на вход в виде **токовой петли 4–20 мА**, и превращать их в цифровые
значения (числа), по которым уже работает программа ИВК.

## Почему именно ток 4–20 мА

Это международный промышленный стандарт передачи аналогового сигнала:

- **4 мА** — «нижний» уровень, соответствует минимальному значению измеряемой
  величины (например, 0 °C);
- **20 мА** — «верхний» уровень, соответствует максимальному значению
  (например, 100 °C);
- между 4 и 20 мА ток пропорционален измеряемой величине, так что пересчёт
  простой линейный.

Важный плюс токовой петли: ток **практически не зависит от длины и сопротивления
провода** (в отличие от напряжения, которое «проседает» на проводах). Поэтому
4–20 мА надёжно работает на длинных линиях до датчиков на объекте.

## Что внутри

Внутри модуль устроен так: на каждом из 24 входов стоит точно подобранный
резистор (**шунт**), который превращает ток в напряжение; это напряжение
подаётся на один из трёх **24-битных АЦП (ADS1256, по 8 каналов на чип)**;
цифровые отсчёты уходят по общей SPI-шине в микроконтроллер **ESP32-S3**,
который пакетирует данные и отдаёт их в ИВК по шине **Modbus RTU via RS-485**.
Чтобы ремонтники 24-вольтового поля не «сожгли» цифровую часть, между ними
поставлена **гальваническая развязка**.

Каналы не размножаются мультиплексором: у каждого чипа свой выбор (CS0..CS2),
поэтому «шаг» по каналам делается просто переключением трёх GPIO — это даёт
24-битную точность на каждом входе (16 бит не хватало бы для нужного разрешения).

```
24 входа (4–20 мА)
   │  шунты → защита → фильтр
   ▼
3× ADS1256 (24 бита, по 8 каналов) ── общая SPI + CS0..CS2 ──► ESP32-S3
                                                                  │
                                            Modbus RTU via RS-485 ▼
                                                                  ИВК
```

## Связано с кодом

| Идея | Где в коде |
|------|------------|
| 24 канала | `CHANNEL_COUNT` — `core/src/channels.rs` |
| «Ток в мА» как основная величина | `Calibration::current_ma` — `core/src/calib.rs` |
| 3× АЦП, выбор кристалла | `Ads1256` — `fw/src/ads1256.rs` |
| Выдача в ИВК (Modbus RTU) | `rtu_slave` — `fw/src/rtu_slave.rs` (+ `core/src/register_map.rs`) |
