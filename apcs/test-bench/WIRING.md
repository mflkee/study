# Wiring Guide — ESP32 + MAX3485 + ZK-U485

## Что у тебя есть

| Устройство | Описание |
|-----------|----------|
| HW678 | ESP32-S3 DevKitC (два USB-C) |
| ZK-U485 | USB-to-RS485 конвертер (A, B, GND) |
| MAX3485 модуль | RS485 трансивер (RO, RE, DE, DI, VCC, GND) |

## Модуль MAX3485 — распиновка

```
MAX3485 Module
┌──────────────────────────┐
│                          │
│  RO  ──── Receive Output │──► к ESP32 RX (чтение)
│  RE  ──── Receive Enable │──┐
│  DE  ──── Driver Enable  │──┼── к ESP32 GPIO4 (управление)
│  DI  ──── Driver Input   │◄─┘ от ESP32 TX (передача)
│  VCC ──── Питание 3.3V   │
│  GND ──── Земля          │
│                          │
│  A  ──── RS-485 bus (+)  │
│  B  ──── RS-485 bus (-)  │
│                          │
└──────────────────────────┘
```

## Какой USB-C порт использовать

```
ESP32-S3 HW678
┌─────────────────────────────┐
│                             │
│  USB-C (UART)  ◄── ЭТОТ!   │  ← Программирование + Serial Monitor
│  - CH340/CP2102 мост        │
│  - Виден как /dev/ttyUSB0   │
│                             │
│  USB-C (USB)   ◄── Доп.    │  ← USB-OTG (не для программирования!)
│  - USB Host/Device          │
│  - Зарядка                  │
│                             │
└─────────────────────────────┘

Используй порт UART (ближе кGPIO пинам)!
```

## Важно: закоротить DE и RE на MAX3485

На MAX3485 модуле DE и RE нужно соединить вместе (закоротить).
Это позволяет управлять направлением ОДНИМ проводом от ESP32:

```
GPIO4 = HIGH → DE=HIGH, RE=HIGH → РЕЖИМ ПЕРЕДАЧИ (TX)
GPIO4 = LOW  → DE=LOW,  RE=LOW  → РЕЖИМ ПРИЁМА (RX)
```

На大多数 MAX3485 модулях DE и RE уже стоят рядом — просто поставьте перемычку или спаяйте.
