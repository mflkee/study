# ESP32 Firmware — Modbus RTU Slave

## ДВА РЕЖИМА работы

### Режим 1: USB/COM (без трансивера) — main.rs

Простое подключение к ПК через USB, **без MAX3485 вообще**.

```
ESP32 USB-C (COM/UART) ──────► ПК
```

Это самый быстрый тест: прошиваешь, открываешь COM-порт, шлёшь Modbus-кадры — ESP32 отвечает как Slave. RS-485/трансивер не нужен, потому что Modbus RTU работает по любой последовательной линии, включая USB-виртуальный COM.

- Пины: **UART0**, TX=GPIO43, RX=GPIO44 (автоматически на USB-мост платы)
- Управление направлением **не требуется** (полнодуплекс)
- Хорошо для проверки логики Slave и кадров

### Режим 2: RS-485 + MAX3485 — main_rs485.rs

Полноценная работа по RS-485 через трансивер.

```
ESP32 HW678       MAX3485        Провод
─────────────── │───────────────
GPIO17 (TX) ────►│ DI           ← красная
GPIO18 (RX) ◄────│ RO           ← чёрная
GPIO4        ────│ DE + RE      ← коричневая (DE и RE закоротить!)
3V3          ────│ VCC          ← любая жила
GND          ────│ GND          ← любая жила

MAX3485 A ──────── ZK-U485 A
MAX3485 B ──────── ZK-U485 B
```

**Чтобы собрать режим 2:** скопируй `src/main_rs485.rs` поверх `src/main.rs`.

## Что делает прошивка

Modbus RTU Slave (ID=1) с имитацией датчиков:
- 15 температур (Input Registers 0-29)
- 15 давлений (Input Registers 30-59)
- 2 насоса (Coils 0-1)
- 32 Holding Registers (конфигурация)

## Сборка и прошивка

```bash
cargo install espup
espup install          # установит xtensa-esp32s3 target
cargo build --release  # сборка
cargo run --release    # прошивка
```

## БЫСТРЫЙ ТЕСТ (режим 1, без проводов)

1. Вставь ESP32 в USB.
2. Узнай порт: `ls /dev/ttyUSB*` — это COM платы (напр. `/dev/ttyUSB1`).
3. Открой serial-монитор тем же портом на **115200** (лог прошивки) или прямо запроси Modbus на **9600** с ПК:

```bash
python3 ../scripts/modbus_client.py /dev/ttyUSB1 9600
```

> Внимание: лог прошивки печатается по UART0 на 115200, а Modbus ходит там же.
> Для чистоты теста понизь лог (log::info выводится, но на пакетной скорости 9600 это не мешает, т.к. ответ идёт после приёма кадра).

## Распиновка (режим 2)

| Пин | Назначение |
|-----|-----------|
| GPIO17 | UART1 TX → MAX3485 DI |
| GPIO18 | UART1 RX ← MAX3485 RO |
| GPIO4 | Направление RS-485 (DE+RE) |
| 3V3/GND | Питание MAX3485 (обязательно!) |

## Параметры Modbus

| Параметр | Значение |
|----------|----------|
| Slave ID | 1 |
| Baud rate | 9600 |
| Data bits | 8 |
| Parity | None |
| Stop bits | 1 |
