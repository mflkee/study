# Модуль 00: Мини-проект — кнопка + светодиод по Modbus RTU

Маленький полигон, где всё работает от первого бита до ИВК:
ESP32-S3 управляет светодиодом и читает кнопку по Modbus RTU.

---

## Цель модуля

Пройти полный цикл **от написания ядра до реального опроса**:

1. Понять CRC-16 Modbus «изнутри» (не как чёрный ящик)
2. Разобраться, как dispatch по коду функции превращает байты в ответ
3. Попробовать GPIO на реальном железе (светодиод + кнопка)
4. Увидеть Modbus RTU-кадр в реальном времени через Python-клиент

---

## Связь с курсом

Этот модуль опирается на:

- **Модуль 04** — теория Modbus (PDU/ADU, FC01/FC03/FC05, исключения)
- **Модуль 05** — практика на Rust (tokio-modbus / rmodbus)
- **Модуль 06** — ESP32 + Modbus (UART, регистры)

Мини-проект **не заменяет** их, а даёт короткий «замкнутый контур»:
всё в одном каталоге, без серверной части, без TCP, без промежуточных шагов.

## Предварительные требования

- Установлен ESP-IDF + xtensa-esp32s3 toolchain
- ESP32-S3 DevKitC + USB-кабель
- MAX3485 (или любой UART USB-мост для RS-485)
- `pyserial` (`pip install pyserial`)
