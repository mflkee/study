# Embedded Rust + Modbus: Полный курс

## Цель курса

Подготовка разработчика к реализации промышленного Modbus TCP/RTU шлюза на ESP32-S3 с использованием Rust. Курс охватывает весь путь: от основ Rust до интеграции с Zynq SoC через Ethernet.

## Итоговый продукт

Масштабируемый Modbus TCP Slave (сервер) на ESP32-S3, который:
- Опрашивает до 32 устройств по Modbus RTU через RS-485 (MAX3485)
- Предоставляет доступ к регистрам по Modbus TCP (порт 502) через Ethernet (W5500)
- Конфигурируется динамически без перепрошивки
- Работает в реальном времени с минимальными задержками

## Стек технологий

| Компонент | Технология |
|-----------|-----------|
| Язык | Rust (no_std + embedded) |
| MCU | ESP32-S3 DevKitC |
| Фреймворк | Embassy (async) или esp-idf-hal |
| Протокол | Modbus TCP + RTU |
| Ethernet | W5500 (SPI) |
| RS-485 | MAX3485 (UART) |
| Разработка | Arch Linux, VS Code + rust-analyzer |

## Структура курса

### Модуль 0: [Мини-проект — кнопка + LED по Modbus RTU](00-mini-project/)
Полный цикл «от бита до ИВК»: CRC, dispatch по FC, GPIO, RTU slave loop, Python-клиент.

### Модуль 1: [Rust Fundamentals](01-rust-fundamentals/)
Основы Rust, критичные для embedded-разработки. Ownership, borrowing, lifetime, traits, async/await.

### Модуль 2: [Embedded Rust](02-embedded-rust/)
Rust в мире микроконтроллеров. no_std,(heap), bare-metal, Embassy framework.

### Модуль 3: [ESP32-S3 Setup](03-esp32-setup/)
Настройка.toolchain. Прошивка. Первые примеры. Распиновка и периферия.

### Модуль 4: [Modbus Protocol](04-modbus-protocol/)
Теория Modbus. RTU vs TCP. PDU/ADU. Коды функций. Исключения. Адресация.

### Модуль 5: [Modbus on Rust](05-modbus-rust/)
Практика: реализация Modbus на Rust. Крейты (tokio-modbus, rmodbus). Сервер/клиент.

### Модуль 6: [ESP32 + Modbus](06-esp32-modbus/)
Интеграция Modbus на ESP32. UART для RTU. TCP через Ethernet. Регистры.

### Модуль 7: [Gateway Project](07-gateway-project/)
Сборка шлюза. RTU Master + TCP Slave. Конфигурация. Тестирование.

### Модуль 8: [Advanced Topics](08-advanced-topics/)
Безопасность. Производительность. Масштабирование. Интеграция с Zynq/SCADA.

### Модуль 9: [AI-32 — аналоговый ввод 4–20 мА](09-ai32-module/)
24 канала 4-20 мА → ESP32-S3 → Modbus RTU via RS-485: 3×ADS1256 на общей SPI (3 шины, CS0..CS2), дебаунс, sim-режим, ИВК-клиент, 16 тестов ядра.

## Рекомендуемый темп

- **Модуль 0: 1–2 дня** (мини-проект: полный контур на одном столе)
- Модули 1-3: 2-3 недели (база)
- Модули 4-5: 2 недели (протокол + практика на Rust)
- Модули 6-7: 2-3 недели (интеграция + сборка)
- Модуль 8: 1 неделя (углубление)
- Модуль 9: 1 неделя (24 канала 4-20 мА + ИВК)

**Итого: 8-10 недель** при 2-3 часах в день.

## Предварительные требования

- Базовое понимание программирования (любой язык)
- Установленный Arch Linux
- ESP32-S3 DevKitC
- USB-кабель Type-C
- Желание разбираться в промышленных протоколах

## Как использовать курс

1. Начинайте с модуля 1, если нет опыта с Rust
2. Каждый модуль содержит: теорию, примеры кода, упражнения
3. Выполняйте упражнения последовательно
4. Не пропускайте модули — каждый опирается на предыдущий
5. Финальный проект (модуль 7) объединяет всё изученное
