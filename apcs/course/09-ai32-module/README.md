# Модуль 9: AI-32 — учебное пособие на реальной задаче

> **Реальная задача:** спроектировать, прошить и «запустить в ИВК» промышленный
> модуль аналогового ввода **AI-32** — 24 канала токовой петли 4–20 мА на
> ESP32-S3 + 3× ADS1256 (24 бита), отдающий данные по Modbus RTU via RS-485.

На этом модуле сходится **весь курс**: чистая логика без железа (`core`),
прошивка (`fw`), протокол, калибровка, клиент ИВК и тесты. Это финальная
«сборка» навыков из модулей 01–08 в законченный узел.

## Постановка задачи (ТЗ)

### Что должен делать модуль

```text
Датчики 4..20 мА (24 шт.)  ─►  AI-32  ── Modbus RTU (RS-485) ─►  ИВК
```

- читать **24 канала** тока 4–20 мА; превращать код АЦП в **миллиамперы**;
- выдавать измеренные токи в ИВК по **Modbus RTU via RS-485**:
  - FC04 — ток канала (`f32`, 2 регистра на канал);
  - FC03 — калибровка channel: `gain`/`offset` (read-only);
  - FC01/FC02 — «включён ли канал»;
  - FC05 — можно включить/выключить канал из ИВК;
  - FC06 — любой write holding → exception 0x04 (калибровка живёт в NVS);
- хранить калибровку в **NVS** (переживает перезагрузку);
- работать **двумя способами**: на реальной плате (общая SPI + 3× ADS1256) и в
  **sim-режиме** (виртуальные датчики — синусы 4.8..19.2 мА) — для разработки
  без железа.

### Инженерные вводные (кратко)

Модуль спроектирован так (подробно — [`ai32/docs/`](../ai32/docs/README.md)):

| Узел платы | Что и почему | Глава docs |
|---|---|---|
| Шунт 165 Ом, 0.1 %, 25 ppm/°C | ток → напряжение 0.66..3.3 В | 03 |
| Защита входа (24.9 Ом, TVS, PTC) | пережить «24 В на клемму» | 04 |
| RC-фильтр 1 кОм + 100 нФ | антиалиасинг, 1.59 кГц | 05 |
| OPA320 (повторитель, 5 В) | согласовать фильтр и вход АЦП | 06 |
| 3× АЦП ADS1256 (24 бита) | канал на вход: LSB 0.305 мкВ ≈ 0.00185 мкА/код | 07, 10 |
| Общая SPI + CS0..CS2 (3 GPIO) | 24 канала на три чипа по 8, без мультиплексоров | 09 |
| Развязка B0505S + изоляторы | поле/цифра: отдельные земли | 08, 11 |
| ESP32-S3 (HW-678) | Modbus RTU slave по RS-485 | 15 |

### Что вы получите в итоге

```text
python3 ai32/scripts/ive_client.py /dev/ttyUSB0 poll
# → живой «табло» 24 каналов, как в SCADA
```

## Проверка

Финальный чек-лист (быстрый способ убедиться, что модуль «готов»):

```bash
# 1) Чистое ядро — логика без железа
cd ai32/core && cargo test                 # 16 passed (+ ваши тесты)

# 2) Прошивка в ОБОИХ режимах — sim и реальный
cd ai32/fw
cargo +esp check                           # sim
cargo +esp check --no-default-features     # real SPI/GPIO

# 3) «ИВК против живого модуля» — sim или реальная плата
python3 ai32/scripts/ive_client.py /dev/ttyUSB0          # разовый опрос
python3 ai32/scripts/ive_client.py /dev/ttyUSB0 poll     # цикл (2 c)
```
