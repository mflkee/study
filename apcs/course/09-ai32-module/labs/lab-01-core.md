# Лабораторная 1. Фундамент: чистое ядро AI-32

> [Все лабораторные](README.md)

## Цель

Убедиться, что «логика без железа» (`ai32-core`) собирается, работает и
тестируется на любом ПК. Осмыслить физику калибровки и устройство карты
регистров — это фундамент всех следующих лабораторных.

## Вводные

Читать код, не запуская ничего, — скучно и бесполезно. Поэтому:

- **[`calib.rs`](../../ai32/core/src/calib.rs)** — калибровка: LSB = 5.12/16_777_216
  мкВ, шунт 165 Ом, формула `I = gain·code + offset`. Тесты там же.
  Соответствует главам [03 (шунт)](../../ai32/docs/03-shunt.md) и
  [07 (диапазон АЦП)](../../ai32/docs/07-adc-scaling.md) документации.
- **[`channels.rs`](../../ai32/core/src/channels.rs)** — 24 канала: ток + флаг
  «включён».
- **[`register_map.rs`](../../ai32/core/src/register_map.rs)** — карта Modbus
  FC01..FC06.

## Шаги

1. **Соберите и прогоните тесты ядра:**

   ```sh
   cd ai32/core && cargo test
   # 16 passed; 0 failed
   ```

   Обратите внимание: никакого esp-тулчейна не нужно. Почему?

2. **Прочитайте `calib.rs` сверху вниз.** Найдите в тестах «любимые числа»
   `N4 = 0.660 / LSB = 2 162 688` и `N20 = 3.300 / LSB = 10 813 440`.
   *Вопрос: что физически значит «код 2 162 688»?* (подсказка: напряжение на
   шунте при 4 мА, поделённое на цену разряда 24-битного АЦП).

3. **Прочитайте `register_map.rs`.** Найдите, почему FC04 у выключенного канала
   отдаёт `0.0` (`bank.current_of(ch).unwrap_or(0.0)`) и почему FC06 всегда
   возвращает `0x04`.

4. **Напишите свой тест — калибровка канала 17.** По образцу
   `holding_regs_show_gain_offset`:

   - поставьте каналу 17 калибровку `Calibration::from_points(2_000_000.0, 12_000_000.0)`;
   - прочитайте FC03 с адреса `17*4`, count = 4;
   - проверьте, что `gain` и `offset` совпадают (с точностью `1e-9`/`1e-4`).

5. **Добавьте тест «FC04 отдаёт 0.0 для выключенного канала»:**
   `set_current(3, 12.5)` → `write_coil(3, false)` → `read_input(bank, 6, 2)` == `[0,0]`.

## Чекпоинт

```text
cd ai32/core && cargo test
# теперь 16 + 2 = 18 passed; 0 failed
```

Если тесты зелёные — вы поняли, как «код АЦП превращается в мА» и как это
видно по Modbus. Переход → [Лабораторная 2](lab-02-sim.md).
