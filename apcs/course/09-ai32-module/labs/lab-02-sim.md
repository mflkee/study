# Лабораторная 2. «Оживить» ИВК без железа

> [Все лабораторные](README.md)

## Цель

Собрать прошивку в sim-режиме и через ИВК-клиент увидеть «живые» показания
24 каналов — **без единого датчика**. Это доказывает, что Modbus RTU-часть,
калибровка и карта регистров готовы, а железо можно дописывать отдельно.

## Вводные

- Как работает sim-бэкенд — **[`sim.rs`](../../ai32/fw/src/sim.rs)**: каждый
  канал — синусоида тока 12 ± 7.2 мА (≈ 4.8..19.2 мА) со своим периодом/фазой.
- Как прошивка выбирает источник данных — [`main.rs`](../../ai32/fw/src/main.rs):
  `Box<dyn AdcBackend>`.
- Клиент ИВК — [`ive_client.py`](../../ai32/scripts/ive_client.py).

## Шаги

1. **Проверьте сборку sim-режима:**

   ```sh
   cd ai32/fw && cargo +esp check
   # Finished `dev` profile ... (0 предупреждений)
   ```

   *Вопрос: какой файл конфигурации подхватывает тулчейн `esp` автоматически?*

2. **Запустите клиент против sim-сервера.** Прошивку в sim-режиме можно
   запустить на реальной плате (она поднимется без АЦП) или через тестовое
   окружение стенда (см. `test-bench/esp32-fw`). Прошивка отдаёт данные по
   RTU через USB-UART (GPIO43/44) или RS-485. Клиент общается по Modbus RTU
   через обычный USB-UART адаптер:

   ```sh
   python3 ai32/scripts/ive_client.py /dev/ttyUSB0          # разовый опрос
   python3 ai32/scripts/ive_client.py /dev/ttyUSB0 poll     # каждые 2 с
   ```

3. **Сопоставьте показания с формулой.** Найдите канал с минимальным текущим
   током (около **4.8 мА**) и максимальным (около **19.2 мА**).
   *Вопрос: откуда берутся эти числа, если АЦП нет?* (подсказка: `sim.rs`,
   `code_for` + `Calibration::ideal`).

4. **Разберите вывод `ive_client.py`.** Найдите в таблице: FC04 (токи),
   FC03 (gain/offset), FC01 (coil). *Вопрос: почему все `coil = 1`?*

5. (по желанию) Запустите `poll` и подождите: синусы **разной фазы/периода**
   визуально «ползут» по каналам. Это и есть «живой» ИВК.

## Чекпоинт

```text
Получено «табло» 24 каналов со значениями в диапазоне 4.8..19.2 мА,
и они меняются со временем. Понятно, откуда они берутся.
```
