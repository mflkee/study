# Примеры модуля 9

Отдельный исполняемый пример не нужен: модуль AI-32 и есть практика.
Здесь — карта «пример → файл репозитория», чтобы вы знали, где смотреть.

## Чистое ядро (`ai32/core`) — читается и без ESP

| Что смотрим | Файл |
|-------------|------|
| Калибровка: 2 точки -> gain/offset | `core/src/calib.rs` |
| 24 канала, включение/выключение    | `core/src/channels.rs` |
| Вся карта регистров FC01..FC06     | `core/src/register_map.rs` |
| CRC-16 Modbus + вектор-пара        | `core/src/crc.rs` |

Каждый файл содержит рабочие unit-тесты рядом с кодом — это и есть
«теория прямо в коде».

## Прошивка (`ai32/fw`) — требует тулчейна esp

| Что смотрим | Файл |
|-------------|------|
| trait `AdcBackend` (источник кода АЦП)  | `fw/src/adc_backend.rs` |
| sim-датчики (синусы 4.8..19.2 мА, без АЦП)| `fw/src/sim.rs` |
| 3× ADS1256: общая SPI + CS0..CS2, чтение | `fw/src/ads1256.rs` |
| RTU-слушатель UART0 (RS-485)             | `fw/src/rtu_slave.rs` |
| NVS-калибровка (C-биндинги, без svc)    | `fw/src/config_store.rs` |
| Точка входа: выбор backend, сканирование| `fw/src/main.rs` |

## Клиент ИВК

| Что смотрим | Файл |
|-------------|------|
| RTU-клиент (CRC16) + «табло» 24 каналов | `scripts/ive_client.py` |

## Распиновка и разбор

| Что смотрим | Файл |
|-------------|------|
| Распайка ESP32-S3 (SPI2, CS0..CS2, UART, питание) | `docs/PINMAP.md` |
| Инженерный разбор — иерархия глав (16 глав + индекс) | [`docs/README.md`](../../ai32/docs/README.md) |
| Устройство одного канала, защита, шунт | [`docs/02-analog-path.md`](../../ai32/docs/02-analog-path.md), [`docs/04-input-protection.md`](../../ai32/docs/04-input-protection.md) |

Как пользоваться: открывайте файл рядом с темой упражнения, читайте
комментарии и тесты, потом меняйте одну вещь и прогоняйте тесты — так
инженерный проект и изучается.
