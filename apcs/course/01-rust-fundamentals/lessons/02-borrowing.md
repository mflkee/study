# 02: Borrowing (заимствование) — &T и &mut T

> **Цель урока:** научиться передавать данные в функцию и обратно без
> перемещения, понимая правила «один писатель ИЛИ много читателей».

## Зачем это про «ссылку»

Вместо того чтобы перемещать значение (и терять его), можно дать
**ссылку** (reference) на место в памяти, где оно лежит. Ссылка —
это и есть «займ» (borrow): владелец остаётся прежним.

```rust
fn len_of(s: &String) -> usize {
    s.len()
}
fn main() {
    let s = String::from("hello");
    let n = len_of(&s);   // &s — одолжили, а не отдали
    println!("{s}");      // s всё ещё у нас!
}
```

## Два сорта ссылок

| Тип ссылки   | Смысл                        | Сколько может быть |
|--------------|------------------------------|--------------------|
| `&T`         | ссылка для чтения (иммутабельная) | много, одновременно |
| `&mut T`     | ссылка для записи (мутабельная)   | ровно одна         |

### Правило «один писатель ИЛИ много читателей»

```rust
let mut s = String::from("hello");

let r1 = &s;      // читатель 1
let r2 = &s;      // читатель 2
println!("{r1} {r2}");          // 🌳 много читателей — ОК

let w = &mut s;  // писатель — но ТОЛЬКО один, и читатели закончили
w.push_str("!");
```

### Что запрещается

```rust
let mut s = String::from("hello");
let r = &s;
let w = &mut s;   // ❌ E0502: уже есть immutable-займ
```

Rust запрещает одновременно иметь ссылку на чтение И мутабельную ссылку,
потому что мутация могла бы «переместить» данные прямо под читателем.

## Borrowing в методах структур

```rust
struct ModbusFrame { bytes: Vec<u8> }

impl ModbusFrame {
    fn len(&self) -> usize { self.bytes.len() }   // &self — ссылка на структуру
    fn push(&mut self, b: u8) { self.bytes.push(b) } // &mut self
}
```

`&self` и `&mut self` — синтаксический сахар над `&ModbusFrame` и
`&mut ModbusFrame`. Именно поэтому в TUI у `Emulator` методы типа
`tick(&mut self)` (эмулятор мутирует датчики) и `devices(&self)`
(только читает).

## Итог: правила, которые надо запомнить

1. Ссылок на чтение можно много, они не хоронят владельца.
2. Мутабельная ссылка — всего одна в момент времени.
3. Ссылка из функции живёт не дольше данных, которые она одалживает.

## Маленькая подсказка

Если IDE (rust-analyzer) подсвечивает ошибку заимствования — чаще всего
нужно *сузить область жизни* ссылки скобками `{}` или взять значение
по значению (`let v = data[0];`) там, где это допустимо.
