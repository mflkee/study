## Таблица соединений

### RS-485 (UART)

| ESP32 Pin | MAX3485 Pin | Функция |
|-----------|-------------|---------|
| GPIO17 (TX) | DI | Данные передачи |
| GPIO18 (RX) | RO | Данные приёма |
| GPIO4 | RE + DE | Управление направлением |
| 3V3 | VCC | Питание |
| GND | GND | Земля |

### Ethernet (SPI)

| ESP32 Pin | W5500 Pin | Функция |
|-----------|-----------|---------|
| GPIO12 (SCK) | SCK | Тактовый сигнал |
| GPIO11 (MOSI) | MOSI | Master Out Slave In |
| GPIO13 (MISO) | MISO | Master In Slave Out |
| GPIO10 (CS) | CS | Chip Select (active low) |
| GPIO14 | INT | Прерывание (опционально) |
| 3V3 | VCC | Питание |
| GND | GND | Земля |

### RS-485 Bus

| Сигнал | Описание |
|--------|----------|
| A | Положительная линия (дифференциальная) |
| B | Отрицательная линия (дифференциальная) |
| GND | Общая земля (рекомендуется) |

## Важные замечания

1. **Питание:** Все модули питаются от 3.3V (не 5V!)
2. **TERM:** Рекомендуется установить терминирующие резисторы (120 Ом) на концах шины RS-485
3. **Скрутка:** Используйте витую пару для RS-485 (длина до 1200м при 9600 baud)
4. **Экранирование:** Для промышленных условиях используйте экранированный кабель
