## Упражнения

### Упр. 3.1: Hello World
Прошейте ESP32-S3 примером "Hello World" через UART. Проверьте вывод в `screen /dev/ttyUSB0 115200`.

### Упр. 3.2: LED Blink ( hardware)
Настройте GPIO2 (встроенный LED на многих DevKit) для мигания.

### Упр. 3.3: UART Loopback
Замкните GPIO17 на GPIO18 (TX на RX). Отправляйте данные и проверяйте приём.

### Упр. 3.4: SPI Probe
Подключите W5500 и попробуйте прочитать его регистр IDENT (0x39). Если значение 0x52 — модуль найден.

## Проверка

```bash
# Проверка подключения ESP32
ls /dev/ttyUSB* /dev/ttyACM*

# Проверка串口 monitor
screen /dev/ttyUSB0 115200
```
